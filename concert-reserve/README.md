# コンサート予約システム（Google Apps Script）

スプレッドシートに紐づけて使う、シンプルな予約受付です。

- **予約フォーム**：名前・フリガナ・メール・電話番号・枚数・支払い方法（銀行振込／クレジットカード）を受け付け、確認メールを自動送信
- **予約シート**：1予約1行。入金状況・キャンセル・来場を管理
- **受付画面**：当日スマホで名前を検索して「来場」を記録（合言葉つきURL）

## セットアップ

1. 予約管理用のスプレッドシートを開き、**拡張機能 → Apps Script** を開く
2. 次の3ファイルを作って、このフォルダの中身をそのまま貼り付ける
   - `コード.gs` ← `Code.gs`
   - HTMLファイル `form` ← `form.html`
   - HTMLファイル `checkin` ← `checkin.html`
3. 関数 `setup` を選んで **実行**（初回は権限の承認が出ます）。「設定」「予約」シートができます
4. 「設定」シートの **振込の案内・カード決済の案内・問い合わせ先・定員** などを入力
5. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. デプロイ完了画面（または **デプロイを管理**）に出る **ウェブアプリのURL**（`…/exec`）が予約フォームのURL。「設定」シートの「予約フォームURL」に貼っておく
7. メニュー **予約システム → フォーム・受付画面のURLを表示** で、合言葉つきの受付画面URLも確認できる

コードを直したときは「デプロイを管理 → 編集 → 新バージョン」で更新します（URLは変わりません）。

## 設定シート

| 項目 | 内容 |
|---|---|
| 定員 | 販売する合計枚数。**空欄なら上限なし**。キャンセルにした予約の分は自動で戻る |
| 受付状態 | 「受付中」以外にすると受付停止 |
| 振込期限日数 | 予約日から何日以内か（既定 7）。**公演前日のほうが早ければ前日が期限**。公演当日の予約は当日受付払い |
| 振込の案内 / カード決済の案内 | 確認メールと完了画面に載る文面。`{名前}` `{予約番号}` `{枚数}` `{合計}` `{期限}` は予約ごとの内容に置き換わる |
| カード決済URL | カード決済ページのURL。あとから入力可。案内文の `{決済URL}` に入る（空欄の間は「準備ができ次第ご案内」と表示） |
| 通知先メール | 入れると予約のたびに主催者へ通知 |
| 受付画面の合言葉 | 受付画面URLの `key=`。漏れたら書き換える |

## 運用

- 入金を確認したら「入金状況」を **済** に（受付画面からも変更可）
- キャンセルは「状態」を **キャンセル** に（行は消さない）
- 無料のGoogleアカウントはメール送信が1日100通まで。送信に失敗した予約は備考に「【確認メール送信失敗】」と残ります
