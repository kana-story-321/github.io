# 引受判定AI Webアプリ版 セットアップ&デプロイ手順

## 完成イメージ

- スプレッドシートがデータベース(引受判定マスタ 25行)
- GAS が Gemini API を呼び出して判定
- **ブラウザから URL でアクセスできる Web アプリ** として提供
- お客様情報 + 検討商品 を入力 → 20〜30秒で 判定結果(該当条件ID・理由・対応・次のアクション)
- デモ用に 8つのテストシナリオを "1クリックで読込" ボタンで用意

**サイドバー版との違い**:
- Web アプリ版はブラウザで動く独立URL、スプシを開かなくてOK
- スマホ・タブレットからも使える
- 若手代理店に URL を配布するだけで使ってもらえる

## 事前準備 (20分)

### 1. Gemini API キー取得(5分)

1. [Google AI Studio](https://aistudio.google.com/apikey) にログイン
2. 「Create API key」→ `AIzaSy...` の文字列をメモ
3. ⚠️ 他人と共有・SNS投稿・コード直書き は絶対NG

### 2. スプレッドシート準備(3分)

1. `引受判定マスタ_テンプレ.xlsx` を Google ドライブへアップロード
2. 右クリック →「Google スプレッドシートで開く」
3. 「引受判定マスタ」シートに 25行のルールが入っていることを確認

### 3. GAS プロジェクト準備(5分)

1. スプシで「拡張機能」→「Apps Script」を開く
2. デフォルトの `Code.gs` を全消し → **`Code_引受判定.gs` の中身を貼付**
3. 左の+アイコン → 「スクリプト」→ ファイル名 **`Code_WebApp追加`** で新規追加
4. `W2_Code_WebApp追加.gs` の中身を貼付
5. 左の+アイコン → 「HTML」→ ファイル名 **`WebApp`** で新規追加
6. `W2_WebApp.html` の中身を貼付
7. 保存(Ctrl+S / Cmd+S)

### 4. API キーをスクリプトプロパティに登録(2分)

1. GAS エディタ 左サイドバー「⚙ プロジェクトの設定」
2. 下にスクロール →「スクリプトプロパティ」→「スクリプトプロパティを追加」
3. プロパティ: `GEMINI_API_KEY` / 値: (メモした AIzaSy... の文字列)
4. 保存

### 5. 動作確認(5分)

1. GAS エディタで `testSetup` を選択して実行 → 権限承認
2. ログに以下が出れば成功:
   ```
   GEMINI_API_KEY: AIzaSy...(OK)
   マスタ表 行数: 25
   商品リスト: A社生命 / 医療プレミアム, A社生命 / 死亡プレミアム, ...
   ```

## Web アプリとしてデプロイ (10分)

### 1. デプロイの設定

1. GAS エディタ 右上「デプロイ」→「新しいデプロイ」
2. 種類の選択(歯車アイコン)→ **「ウェブアプリ」**
3. 設定:
   - 説明: `引受判定AI v1.0`
   - 次のユーザーとして実行: **自分**
     - → 誰が使っても、あなたの権限で API 呼び出し + スプシ書き込みが動く
     - → Gemini API の従量課金も あなた側に来る(無料枠に注意)
   - アクセスできるユーザー: **自分のみ**(まずテスト用)
     - → 本番配布時は「Workspace 内全員」に変更
4. 「デプロイ」ボタン

### 2. 初回の権限承認

1. 「アクセスを承認」ボタン
2. Google アカウント選択
3. 「このアプリは Google で確認されていません」→ 「詳細」→「安全ではないページに移動」
   > ⚠️ 自分で作ったアプリなので許可してOK
4. 権限を確認 →「許可」

### 3. Web アプリ URL の取得

1. 発行された **ウェブアプリ の URL** をコピー
2. ブラウザ(または別ブラウザのシークレットモード)で URL を開く
3. Web アプリのフォームが表示されれば成功

## 動作テスト(10分)

### テスト1: デモシナリオで動作確認

1. Web アプリを開く
2. 上部の「💡 テストシナリオを読込 (デモ用)」から **「#1 高血圧180超 × A社医療」** をクリック
3. フォームが自動入力される
4. 「▶ 判定する」ボタン
5. 20〜30秒後に 判定結果カードが表示される

### 期待結果(#1 のケース)

- 判定: **NO**(赤バッジ)
- 該当条件ID: **RULE-004**
- 判定理由: 「収縮期185mmHg は "高血圧180超" に該当し、A社医療プレミアムでは引受不可」
- 対応: 「代替: D社医療ライト(緩和型)を検討 or 血圧安定後に再申込」
- 次のアクション: 「顧客への説明: 現状の血圧値では A社医療プレミアムの引受基準に届かないため…」

### テスト2: 商品を切り替えて再判定

1. 「#2 同顧客 × D社医療ライト」ボタン → 同じ顧客情報だが商品だけ D社に
2. 「▶ 判定する」→ 判定: **YES**(緑バッジ)、RULE-023 発火

### テスト3: 該当なしフォールバック

1. 「#7 該当なしエッジ」→ プロサッカー選手 × A社死亡
2. 「▶ 判定する」→ 判定: **該当なし**(グレーバッジ)、"商品担当に事前確認要"
3. → AI が勝手にYESと言わない安全弁が働くことを確認

## 本番配布(全員に使ってもらう)

### 1. アクセス範囲を "Workspace内 全員" に変更

1. GAS エディタ「デプロイ」→「デプロイを管理」
2. 既存デプロイの ✏編集アイコン
3. 「アクセスできるユーザー」を **「Workspace 内全員」** or **「特定ユーザー」** に変更
   > ⚠️ 「全員(限定なし)」は 顧客情報を扱うため NG
4. 「デプロイ」ボタン

### 2. URL を配布

- Slack / メール / 社内Wiki で URL を共有
- 各ユーザーは URL を開くだけで使える(スプシを開く必要なし)
- モバイル・タブレットからもアクセス可能

### 3. 使い方1枚メモを添付

配布時に "使い方" を1枚にまとめて添付:

```
【引受判定AI 使い方】

1. URL を開く: https://script.google.com/macros/s/xxx/exec
2. お客様情報を入力(氏名等の個人特定情報は入れない、"45歳男性" 等の属性で)
3. 検討中の商品を選ぶ
4. 「▶ 判定する」ボタン
5. 20〜30秒で判定結果が表示

⚠️ AI 判定は "参考"、最終判断は 保険会社の査定です
⚠️ NG判定でも 対応欄に 代替商品案内 が入るので、そのまま活用できます
⚠️ 該当なし の場合は 商品担当に事前確認をしてください
```

## コード更新時の再デプロイ

コードや HTML を修正したら、必ず 新しいバージョンとして再デプロイ:

1. GAS エディタ「デプロイ」→「デプロイを管理」
2. 既存デプロイの ✏編集
3. 「バージョン」→ **「新しいバージョン」** を選択(重要)
4. 説明: `v1.1 - XXX修正` 等
5. 「デプロイ」

> ⚠️ 毎回「新しいデプロイ」で作ると URL が別物になり、配布した URL が古いまま動く
> → 必ず 「デプロイを管理」から 既存デプロイの ✏編集 で更新すること

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| URL を開いても白画面 | 権限承認が済んでいない。GAS エディタで `testSetup` を実行して承認 |
| 「このアプリは Google で確認されていません」 | 通常表示、実害なし。「詳細」→「安全ではないページに移動」で先へ |
| デモボタンが「読込中…」のまま | `getTestScenariosForWebApp` の権限未承認、または `Code_WebApp追加.gs` が貼付漏れ |
| 商品リスト「読込エラー」 | スプシに「引受判定マスタ」シートが無い or 25行のルールが空 |
| 「Gemini API エラー(429)」 | 無料枠のレート制限、1〜2分待ってリトライ |
| 判定結果が空 | Gemini 応答の JSON パースエラー、GAS エディタで実行ログ確認 |
| 別ユーザーで動かない | アクセス範囲を「Workspace 内全員」に変更、または個別追加 |
| コード変更が反映されない | 「デプロイ管理」→ 編集 → 新しいバージョン を選び直す |

## セキュリティ考慮事項

- **API キー**: スクリプトプロパティ経由を厳守、コード直書き絶対NG
- **顧客情報**: URL に顧客名を含めない、フォームには "属性表現" で入力
- **アクセス範囲**: 「全員(限定なし)」は避け、Workspace内 or 特定ユーザーに
- **判定履歴**: 「判定履歴」シートに全実行が記録される → 個人情報保護の観点で閲覧権限を管理職に限定
- **監査**: 「実行ユーザー」= 自分 なので、他人が使っても API 課金は自分。月次で使用量確認

## 発展課題

1. **判定結果を PDF 化**: 生成された判定を PDF レポートで出力、顧客説明資料に
2. **一括判定**: 顧客リスト(CSVアップロード)を一括判定
3. **判定履歴の分析**: 月次で "よく発火するルール" を集計、ノウハウ強化
4. **モバイル最適化**: スマホでの入力しやすさを更に改善(既に基本対応済み)
5. **他ツール連携**: 判定結果を Slack に自動投稿 or 保険会社の申込システム連携
