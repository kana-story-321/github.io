# 【演習1】散在ナレッジを 商品別マスタ表 10列に統合

## 進め方

1. まず 記入例シートを 5分眺めて **完成イメージ** を掴む
2. `引受判定マスタ` シートを開く(空欄テンプレ)
3. デモナレッジ 01 → 02 → 03 → 04 → 05 → 06 の順に開き、1件ずつ条件を抽出して 1行ずつ書く

5. 20〜30 行を目標に。埋めきれない項目は "要確認" で残してOK

# 【演習2】"この商品で通る?" AI一次判定 と 更新運用

## 進め方

1. マスタ表(記入例シート)を **CSV でコピー**
2. Gemini に貼り付けて 3ケース判定
3. 同じ顧客で **別商品での再判定**
4. **該当なしテスト**
5. 更新ログに 2件記入
6. 月次見直し会議のアジェンダを決める

---

## ケース1: 45歳男性 / 高血圧185mmHg / A社医療プレミアム

### 生徒が投げるプロンプト

```
あなたは保険代理店の「引受判定サポートAI」です。
以下は うちの代理店が扱う 商品ごとの引受判定マスタ表(CSV)です。

RULE-001,A社生命,医療プレミアム,年齢,加入希望者が満18歳未満 or 満75歳超,NO,加入年齢範囲外,加入年齢は満18〜75歳とご案内,A社商品パンフ / A社研修 v2024,2026-07-14 佐藤
RULE-002,A社生命,医療プレミアム,健康,高血圧 コントロール良好(160未満),YES,血圧安定なら通常引受,追加確認: 主治医のコントロール良好診断書,A社研修資料 v2024 §3.2,2026-07-14 佐藤
RULE-003,A社生命,医療プレミアム,健康,高血圧 160超〜180未満,要確認,160超で査定に回る,追加確認: 直近3ヶ月血圧記録+診断書。1〜2週間の査定期間,A社研修資料 v2024 §3.2,2026-07-14 田中
RULE-004,A社生命,医療プレミアム,健康,高血圧 180超,NO,180超は 医療プレミアムで引受不可,代替: D社医療ライト(緩和型)を検討 or 血圧安定後に再申込,A社研修資料 v2024 §3.2 / A社営業田中さん 2024/06,2026-07-14 田中
RULE-005,A社生命,医療プレミアム,既往歴,直近1年以内に入院歴あり,NO,入院歴1年以内は 医療プレミアムでNG,代替: D社医療ライト検討 or 完治から1年経過後に再申込,A社研修資料 v2024 §4.1,2026-07-14 田中
...(以下 RULE-025 まで)

これをルールとして、次の顧客が指定した商品に申し込む場合、通るかを判定してください。

顧客: 45歳男性 / 高血圧治療中(1年経過、収縮期185mmHg)
検討中の商品: A社医療プレミアム

出力形式:
- この商品での判定: YES / 要確認 / NO
- 該当した条件ID: RULE-XXX
- 判定理由: 1〜2文
- 対応: 再申込タイミング / 代替商品案内 / 追加確認事項
- 次のアクション: 誰に確認するか、顧客に何を伝えるか

該当ルールがない場合は「該当なし → 商品担当に事前確認要」と返してください。
最終判定は保険会社が行います。
```

### AI 出力例

```
- この商品での判定: NO
- 該当した条件ID: RULE-004
- 判定理由: 収縮期185mmHg は「高血圧180超」に該当し、A社医療プレミアムでは引受不可(NG)と定められているため。
- 対応:
  1. 代替商品として D社医療ライト(引受基準緩和型)の検討を提案。
     3項目告知(過去1年入院・5年手術・がん治療)いずれも該当なしなら加入可能(RULE-023)。
  2. または、血圧が160未満まで安定してから A社医療プレミアムに再申込。
     コントロール良好が1年以上続けば RULE-002(YES) の判定に切り替わる。
- 次のアクション:
  - 顧客への説明: 「現状の血圧値では A社医療プレミアムの引受基準に届かないため、
    引受基準緩和型の D社医療ライトをまずご案内します」
  - 内部: D社医療ライトの3項目告知書を準備、顧客にヒアリング
```

### 講師が生徒に確認する点

- ✅ 「該当した条件ID」が **RULE-004** と 明示されている(監査可能)
- ✅ NG で終わらず「対応」に **代替商品(D社医療ライト)** と **再申込タイミング** の両方が出ている
- ✅ 顧客への説明フレーズが出ている(そのまま使える)

## ケース2: 同じ顧客で別商品(D社医療ライト)に切り替え

### プロンプト(顧客情報は同じ、検討中の商品だけ変更)

```
顧客: 45歳男性 / 高血圧治療中(1年経過、収縮期185mmHg)
検討中の商品: D社医療ライト
※3項目告知(過去1年入院・5年手術・がん治療)いずれも該当なしと仮定
```

### AI 出力例

```
- この商品での判定: YES
- 該当した条件ID: RULE-023
- 判定理由: D社医療ライトは引受基準緩和型商品で、3項目告知に該当なしなら加入可能。
  高血圧については3項目告知の対象外のため引受に影響しない。
  加入年齢(45歳)も対象範囲(満40歳〜満80歳)内(RULE-024 に該当せず)。
- 対応:
  - 追加確認: D社医療ライトの3項目告知書のチェック(顧客に記入いただく)
- 次のアクション:
  - 顧客への説明: 「D社医療ライトなら加入可能です。3項目告知書をご記入お願いします」
  - 内部: D社の申込書パッケージ準備
```

### 講師が生徒に確認する点

- ✅ 同じ顧客でも **商品を切り替えたら 別の条件ID(RULE-023)** が返る
- ✅ **商品カルテとして機能** している(商品ごとに判定ルールが分かれている)
- ✅ 高血圧185mmHg の情報は 緩和型では判定に使われない(D社の告知3項目に高血圧が含まれないから)

## ケース3: 該当なしテスト(勝手にYESと言わせない)

```
顧客: 33歳男性 / 健康状態問題なし / 職業: プロサッカー選手
検討中の商品: A社死亡プレミアム
```

### AI 出力例

```
- この商品での判定: 該当なし → 商品担当に事前確認要
- 該当した条件ID: なし
- 判定理由: プロサッカー選手はマスタ表に明示的な条件がありません。
  A社研修 §5.4 の「危険職業(スタントマン、レーサー等)」に該当するかは
  A社商品担当の判断が必要です。

  - A社商品担当(田中さん)に「プロサッカー選手は職業リスクとしてどう扱われるか」を事前照会

  - 内部: A社田中さんにチャットで事前照会 → 回答後に顧客連絡
  - 顧客への説明(暫定): 「職業リスクの確認をA社に問い合わせ中、2〜3営業日でご連絡します」
```

### 講師が生徒に確認する点

- ✅ AI が **勝手に YES と判定していない**
