# 第17回 v2 ─ ライフプランAI 3ワーク構成

## v2 の全体像

従来の 2ワーク版(W01=入出力設計、W02=GAS実装)を **3ワーク構成に拡張**:

```
[ワーク① 設計]         [ワーク② バイブコーディング]     [ワーク③ デプロイとテスト]
DB設計                  GAS + Gemini 実装              デプロイ (UI別)
判断基準・数値の分類    UI 実装 (W1で選んだ形式)         5シナリオ精度検証
UI設計 (3択から選ぶ)    独自アドバイスの組込み          運用ルール確定
独自アドバイス言語化
```

**AI初心者向け設計**:
- **W1**: コード書く前に "何を作るか" を全部言語化 → 手戻り防止
- **W2**: バイブコーディング(AI に頼んで貼付)で "動くもの" を短時間で作る
- **W3**: デプロイして使える形にし、シナリオテストで精度を掴む → 現場運用へ

## ワーク① 設計書を作る(3時間)

### 演習1: DB設計 と 判断基準・数値の設計 (90分)

**DB設計**: スプシに持たせる 3〜5シート:
- 顧客カルテ(顧客ごとの情報)
- 前提テーブル(全顧客共通の 経済前提・教育費相場)
- **独自アドバイスマスタ** ← 代理店の強み
- シミュレーション履歴(監査・改善)
- Docs出力アーカイブ

**判断基準・数値**: 各数値を 3種で分類:
- **公的**(国発表): 物価上昇率、公的年金、教育費相場 (文科省)
- **独自**(代理店の実測 or 判断): 地域補正、リフォーム相場、投資リターン控えめ想定
- **計算式**: 破綻判定、リスク期間、貯蓄残高の累積

### 演習2: UI設計 と 独自アドバイスの言語化 (90分)

**UI 3択**:
| 形式 | 向き | デプロイ |
|---|---|---|
| A: サイドバー | 面談中の即時試算 | スプシ共有だけ |
| B: WebApp | 訪問中/支店複数 | GASでデプロイ URL発行 |
| C: フォーム | 若手入力→ベテラン確認 | フォーム+トリガー |

**独自アドバイス**: 発動条件+提案商品タイプ+提案文言テンプレ+根拠 で3〜5パターン
- 例: 「30代夫婦+子2人」→ 学資保険+個人年金の並行推奨
- 例: 「40-50代単身+貯蓄薄」→ 就業不能保険 最優先
- 例: 「経営者 年収1000万超」→ 事業保険+定期(逓減型)

## ワーク② バイブコーディング(3時間)

### 演習1: メイン処理をバイブコーディング (100分)

- W1 設計書 を Gemini に貼付 →「この通りに GAS 書いて」と依頼
- 同梱 `Code_ライフプランAI.gs` が完成形の見本
- 貼付→動かす→エラー時 Gemini に修正依頼 の流れ
- **独自アドバイス** を プロンプト末尾に組み込み → AI が代理店らしい提案を返すように

### 演習2: UI と 顧客向けレポート出力 (80分)

- W1 で選んだ UI形式に応じて:
  - サイドバー選択: `Sidebar.html` 貼付
  - WebApp選択: `WebApp.html` + `W2_Code_WebApp追加.gs` 貼付
- 顧客向け PDF レポート: `Code_レポート生成.gs` 貼付 → 7ページPDF自動生成

## ワーク③ デプロイとテスト(3時間)

### 演習1: デプロイ (100分)

W1 で選んだ UI形式に応じたデプロイ手順:
- **サイドバー**: スプシ共有 (5分、超簡単)
- **WebApp**: GAS デプロイ → URL発行 → 別ブラウザ動作確認 (10分)
- **フォーム**: Googleフォーム作成 + onFormSubmit トリガー (5分)

アクセス範囲: 全員 / Workspace限定 / 特定ユーザー → 個人情報を扱うため **Workspace限定 が基本**。

### 演習2: 5シナリオ実測 + 運用ルール決定 (80分)

**5シナリオ**:
1. 若年子育て世帯(35歳会社員家族4人)— 基本パターン
2. 単身低収入(42歳女性契約社員)— 破綻シナリオ
3. 高収入経営者(45歳男性年収1500万)— 高額保障
4. シニア独身(58歳女性)— 老後1本足打法
5. エッジ(データ不足)— クラッシュしないか

各シナリオで:
- 期待結果と実結果を比較
- 独自アドバイスが発火するか
- シミュレーション履歴シートに記録

**運用ルール確定**:
- 誰が使う / 独自アドバイス更新頻度 / 監査ログ運用 / 顧客見せの承認手順 / 個人情報の扱い
