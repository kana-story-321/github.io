# W3 テストシナリオ集 ─ デプロイ後の精度検証

## テストの目的

デプロイしたライフプランAI が **どんな入力に対してどんな結果を返すか** を把握し、
現場で使う前に "限界と傾向" を掴む。

各シナリオで:
1. 期待結果 と 実結果 が近いか目視
2. 破綻年 / 保険提案フック の内容が妥当か
3. AI が捏造している数値や項目がないか
4. 独自アドバイス(W1 で設計)が反映されているか

---

## テストシナリオ 5件

### シナリオ1: 若年子育て世帯(基本パターン)

**顧客情報**:
- 年齢: 35 / 男 / 会社員 IT / 年収 600万 / 想定退職 65歳
- 配偶者: あり / 33歳 / 年収 250万
- 子: 5歳, 2歳 (2人)
- 貯蓄 500万, 投資 200万
- 住宅ローン 2000万 残25年 金利1.2%
- 月次支出: 生活25/住居10/教育2/保険3/その他5 (合計45万)
- リスク: 夫の就業不能3年 / 妻の育児離職2年
- 要望: 教育費と老後資金の両立、貯蓄型希望

**期待結果**:
- 破綻年: なし
- 最大貯蓄年: 60代前半 (退職直後、退職金1500万含む)
- 最低貯蓄年: 40代後半 (教育費ピーク)
- 保険提案フック: 学資保険 / 個人年金 / 就業不能保険 (3件以上)
- 独自アドバイス「ADV-001」該当 → 学資+個人年金の並行推奨コメント

**確認ポイント**:
- [ ] 40年ぶんのCFが飛び値なく累積している
- [ ] 貯蓄残高の折れ線グラフが妥当な形(V字カーブ)
- [ ] 保険提案フックに 学資保険 + 個人年金 が含まれる

### シナリオ2: 単身低収入(破綻シナリオ)

**顧客情報**:
- 年齢: 42 / 女 / 契約社員 / 年収 250万 / 想定退職 65歳
- 配偶者: なし
- 子: なし
- 貯蓄 100万, 投資 0万
- 住宅ローン なし (賃貸想定)
- 月次支出: 生活20/住居8/教育0/保険2/その他5 (合計35万)
- リスク: 病気での就業不能が最大不安
- 要望: 老後不安、貯蓄増やしたい

**期待結果**:
- 破綻年: 65歳付近 or 70歳付近 で貯蓄0以下になる可能性
- 最大貯蓄年: 65歳退職直後
- 保険提案フック: 就業不能保険 (優先度高) / 医療保険 (シンプル型) / 老後備え商品
- 独自アドバイス「ADV-002」該当 → 単身+貯蓄薄で就業不能保険を最優先提案

**確認ポイント**:
- [ ] 破綻年が明確に出る(顧客に "備える必要性" を可視化)
- [ ] AI 総評で "対策を一緒に考える" トーン(危機感煽りではない)
- [ ] 提案フックに 就業不能保険 が最上位

**顧客情報**:

**確認ポイント**:

- [ ] 独自アドバイス「経営者向け」パターンが発火しているか

**顧客情報**:
- 年齢: 30
- その他: 空欄

**期待結果**:
- エラー or 「必須項目が未入力」アラート

## 精度改善サイクル

テスト結果から「AI の弱点」を発見したら:

1. **プロンプト調整** (Code_ライフプランAI.gs の buildPrompt_ を修正)
   - 「独自アドバイス XXX を必ず反映」を明記
   - 「破綻年は 貯蓄0以下 の年、複数年連続の場合は最初の年」等の判定基準を追記
2. **前提テーブル調整** (前提テーブルシートの数値見直し)
3. **独自アドバイスマスタ追加** (パターン追加、月1回)

改善したら 5シナリオを再テスト → 改善効果を確認 → 履歴に記録
