# 第17回 デモ資材 — ライフプラン シミュレーション AI

## 想定シチュエーション

**保険代理店** が顧客と面談 → ヒアリングした内容を元に **今後40年間のキャッシュフロー** を試算し、
**保険提案フック**(いつどんな保険が必要になりそうか)まで自動で洗い出したい。

従来は Excel でゴリゴリ計算 or 有料FPソフト。両方とも「顧客ごとに前提を変える」のが手間で、
面談 → 試算 → 提案 のリードタイムが長い。

**GAS + Gemini API** で、顧客カルテを埋めるだけで 30秒で 40年 CF + 保険提案フックが出るツールを作る。

## 「顧客カルテ」の設計方針(演習1 の到達物)

- **項目/値/単位 の縦3列** 構成 → 対面で埋めやすい、AI が読みやすい
- 6セクション: 基本情報 / 配偶者 / 子ども(最大3人) / 資産 / 月次支出 / ライフイベント / リスク・要望
- 数値は **万円単位** で統一(Gemini が計算しやすい)
- 「気になるリスク」「その他要望」は自由記述 → AI が総評と保険提案に反映

## 「前提テーブル」の中身(演習1 の到達物)

- **経済前提**: 物価上昇率 / 給与上昇率 / 投資リターン
- **公的年金 月額**: 夫婦 22万 / 単身 15万(令和6年度モデル)
- **教育費相場 年間**: 公立/私立 × 幼小中高大(文科省 子供の学習費調査)
- **老後医療費 追加月額**: 2万円
- **シミュレーション期間**: 40年

年1回の見直しで各社の最新数値に更新。

## 「シミュレーション結果」の中身(演習2 の到達物)

- **40年 CF表** 8列: 年 / 年齢 / 世帯収入 / 生活支出 / 特別支出 / 年間収支 / 貯蓄残高 / 備考
- **サマリ** 5項目: 最大貯蓄年 / 最低貯蓄年 / 破綻年 / リスク期間 / 総評コメント
- **貯蓄残高の折れ線グラフ**(GAS が自動生成)
- **保険提案フック**(別シート、3〜5件): トリガー / 推奨商品タイプ / 推奨金額ヒント / 提案理由

条件付き書式で、収支マイナス=赤、貯蓄200万以下=黄、貯蓄マイナス=濃赤で可視化。

## セットアップ手順 (講師デモ用: 25分)

詳細は `セットアップ手順_GASライフプランAI.md` を参照。要点:

1. `ライフプラン入力テンプレ.xlsx` を Google ドライブへアップ → スプシで開く
2. 「拡張機能」→ Apps Script → Code.gs を消して `Code_ライフプランAI.gs` の中身を貼付
3. HTMLファイル `Sidebar` を追加、`Sidebar.html` の中身を貼付
4. スクリプトプロパティ `GEMINI_API_KEY` を設定
5. `testSetup` を実行して権限承認 & 動作確認
6. スプシに戻ってメニュー「ライフプランAI」→「シミュレーション実行」

## ワーク中に必ず伝える「意味」の問いかけ

| タイミング | 問いかけ |
|---|---|
| 顧客カルテを見た直後 | 「これって既存のヒアリングシートと何が違う?→ AI が計算できる形式で書く」 |
| 前提テーブルを見た時 | 「なぜ前提を分離?→ 顧客ごとに書き直さず 全員共通の前提を1箇所で管理できる」 |
| 出力設計を見た時 | 「なぜ40年? なぜ8列? → 老後まで見通す + 代理店が読み取れる粒度」 |
| GAS を初めて動かした時 | 「AI が数値計算を間違えることがある。前年+収支=当年 が合っているか目視確認」 |
| 保険提案フックを見た時 | 「AI が提案を "勝手に" 決めているように見えるが、あくまで "きっかけ"。最終提案は代理店が行う」 |
| 破綻年が出た時 | 「破綻=悪 ではない。"このシナリオだと破綻する" と客観的に見せて、備えを一緒に考える材料」 |
| 同じ顧客で前提を変えて再実行 | 「投資リターンを1%変えると結果がどう変わる?顧客に "前提次第で結果変わる" を伝える教材にもなる」 |

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「必須項目が未入力」エラー | 顧客カルテの 年齢 / 年収 は必ず入力 |
| 数値計算が明らかに変(貯蓄残高が急増急減) | Gemini の数値精度限界。責任分解として GAS 側で累積計算を行うよう改修も可 |
| 保険提案フックが商品名まで具体的すぎる | プロンプトの `product_type` 説明を「商品タイプ(学資保険等)まで」と明示 |
| グラフが表示されない | シートを一度削除 → メニュー「結果シートを初期化」→ 再実行 |
| 40年ぶんの計算が長い(1分超え) | プロンプトを短縮(前提テーブルの一部だけ渡す)or シミュレーション期間を30年に短縮 |
