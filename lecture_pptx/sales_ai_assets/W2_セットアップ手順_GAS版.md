# W2 セットアップ手順 (B: GAS 版)

## 完成イメージ

- Google スプシに「ノウハウマスタ」「顧客タイプマスタ」を持つ
- GAS + Gemini API でノウハウを根拠にした回答を返す
- 若手はサイドバーで質問 → 30秒で 決めゼリフ付き回答
- 質問履歴が自動で「質問履歴」シートに蓄積

**メリット**: UI自由、履歴分析、他ツール連携、独自ルール組込み可
**デメリット**: 実装工数(30分〜)、Gemini API 使用(無料枠あり)

---

## 事前準備 (20分)

### 1. Gemini API キー取得 (5分)

1. [Google AI Studio](https://aistudio.google.com/apikey) にログイン
2. 「Create API key」→ `AIzaSy...` の文字列をメモ
3. ⚠️ 他人と共有・SNS投稿・コード直書き は絶対NG

### 2. スプシ準備 (3分)

1. `W2_ノウハウマスタ.xlsx` を Google ドライブへアップ
2. 右クリック →「Google スプレッドシートで開く」
3. シート名が「ノウハウマスタ」「顧客タイプマスタ」であることを確認
4. 記入例 20件 + 顧客タイプ 8件 が入っていることを確認

### 3. GAS コード貼付 (5分)

1. 拡張機能 → Apps Script でエディタを開く
2. デフォルトの Code.gs を全消し → `W2_Code_営業ノウハウAI.gs` の中身を貼付
3. 左の＋ → HTML → ファイル名「Sidebar」で追加
4. `W2_Sidebar.html` の中身を貼付
5. 保存

### 4. API キーをスクリプトプロパティに登録 (2分)

1. 左サイドバー「⚙ プロジェクトの設定」
2. 下にスクロール →「スクリプトプロパティ」→「スクリプトプロパティを追加」
3. プロパティ: `GEMINI_API_KEY` / 値: (メモした AIzaSy... の文字列)
4. 保存

### 5. 動作確認 (5分)

1. GAS エディタで `testSetup` を実行 → 権限承認
2. ログに以下が出れば成功:
   ```
   GEMINI_API_KEY: AIzaSy...(OK)
   ノウハウ有効件数: 20
   顧客タイプ件数: 8
   ```
3. スプシに戻って F5 → メニュー「営業ノウハウAI」表示確認

## 動作テスト (10分)

### テスト1: サイドバーで質問

1. メニュー「営業ノウハウAI」→「▶ ボットを開く」
2. サイドバーで:
   - 名前: 「山田(新人)」
   - 顧客タイプ: 選択なし
   - 質問: 「初回訪問で緊張しています。話の切り出し方を教えてください」
3. 「▶ 質問する」→ 20〜30秒で回答が返る

### 期待結果

- 冒頭に「わかる、それ悩むよね」等の共感
- 結論 → 理由 → セリフ例 → 応用のコツ の構造
- 決めゼリフ例(緑背景)が入っている
- 参照ノウハウ ID: NW-001, NW-002 等が表示
- 「質問履歴」シートに 1行 追加されている

### テスト2: 顧客タイプ別

- 顧客タイプ「経営者」を選択 → 「提案で気をつけることは?」
- 経営者向けの回答(要点3つ以内、数字で即決材料等) が返るか確認

### テスト3: ノウハウに無い質問

- 「マンションのポスティング営業のコツは?」(社内ノウハウ範囲外)
- 「該当ノウハウが少ないので、今度先輩に確認を」と正直に返るか確認

詳細は `W3_テストデータ.xlsx` の10パターンで検証。

## デプロイ (若手全員に配布) (5分)

### サイドバー版として配布(推奨、簡単)

1. スプシ右上「共有」→ 若手営業のアドレスを追加
2. 権限: **編集者**(サイドバー実行にスプシ書き込みが必要)
3. 若手側でスプシを開く → メニュー「営業ノウハウAI」→ 使う

### Web アプリ版として配布(応用)

1. GAS エディタ「デプロイ」→「新しいデプロイ」→ 種類:「ウェブアプリ」
2. 次のユーザーとして実行: **自分**
3. アクセス範囲: **Workspace 内**
4. 発行 URL をチームに配布
   (別途 doGet を追加し、WebApp 用の HTML を用意する必要あり)

## 更新運用

### 週次(15分)

- 「質問履歴」シートを見返し、"AI が答えられなかった質問" を発見
- 発見した質問に対するノウハウを「ノウハウマスタ」に追加
- → AI の回答範囲が継続的に広がる

### 月次(30分)

- ベテラン営業に "今月のノウハウ1件" を追加してもらう
- 質問履歴の集計(誰がよく使う、どんな質問が多い)
- トーン設定(Code の TONE 定数)の微調整

### 年次(1時間)

- ノウハウの全件棚卸し(古い情報の "無効化")
- 削除ではなく "有効/無効" 列を「無効」に変更(履歴を残す)

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| メニューが出ない | スプシ再読み込み(F5)、それでも出なければ GAS エディタで `onOpen` を手動実行 |
| API エラー(429) | 無料枠のレート制限、1-2分待ってリトライ |
| API エラー(403) | API キーが無効、Google AI Studio で再発行 |
| 回答のトーンがイマイチ | Code_営業ノウハウAI.gs 冒頭の `TONE` 定数を調整 |
| 参照ノウハウID が空 | プロンプトを強化「必ず参照した ID を返してください」を追記 |
| 履歴が保存されない | 「質問履歴」シート名を確認、GAS の権限を再承認 |
