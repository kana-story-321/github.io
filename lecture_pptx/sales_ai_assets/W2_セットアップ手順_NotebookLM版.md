# W2 セットアップ手順 (A: NotebookLM 版)

## 完成イメージ

- NotebookLM に トップ営業マンのノウハウ資料をアップ
- Gem として保存(トーンをカスタム指示で固定)
- 若手が質問 → NotebookLM が資料を根拠に回答(出典明示)
- 若手全員に URL を共有

**メリット**: コード不要、資料アップだけ、超簡単、出典が明示される
**デメリット**: UI カスタマイズ不可、質問履歴の分析は手動

---

## 事前準備 (15分)

### 1. ノウハウ資料を用意する (10分)

W1 設計書で決めた内容を元に、以下のいずれかの形で資料を作る:

- **オプション A**: `W2_ノウハウマスタ.xlsx` の「ノウハウマスタ」シートを PDF に出力
- **オプション B**: Google Docs で「トップ営業ハンドブック.gdoc」を作成し、ノウハウを箇条書きで記述
- **オプション C**: 既存の営業ハンドブック PDF があれば それを使う

**推奨構成(A社: 資料は Google Docs で作る場合)**:
```
「トップ営業ハンドブック(v1)」
├─ 第1章 初回訪問(NW-001, NW-002)
├─ 第2章 ヒアリング(NW-003〜NW-005)
├─ 第3章 提案・プレゼン(NW-006, NW-007)
├─ 第4章 反対処理(NW-008〜NW-010)
├─ 第5章 クロージング(NW-011, NW-012)
├─ 第6章 フォロー・アフター(NW-013, NW-014)
├─ 第7章 顧客タイプ別対応(NW-015〜NW-018)
├─ 第8章 失敗事例と教訓(NW-019, NW-020)
└─ 付録: 顧客タイプマスタ
```

### 2. NotebookLM で新規ノート作成 (3分)

1. [NotebookLM](https://notebooklm.google.com/) にログイン
2. 「新しいノートブック」→ 名前を「営業ノウハウ AI(社内用)」
3. 「ソース」→「アップロード」 で 上記資料をアップ

### 3. Gem として保存 & トーン設定 (2分)

1. ノートブック上部「カスタマイズ」or チャット下部「+」 → 「カスタム指示」を開く
2. 以下をコピペ:

```
あなたは弊社「トップ営業マンの知恵」をまとめた AI アシスタントです。
若手営業からの質問に対して、以下のトーンで回答してください。

【トーン】
● 先輩っぽく親しみやすい、少し軽口も交える
● 1回の回答は 200〜300字程度、長すぎない
● 回答構造: ① 結論 → ② 理由 → ③ 具体的セリフ例 → ④ 応用のコツ
● 決めゼリフは「トップ営業ならこう言う: 〇〇」の形で必ず入れる
● 冒頭に「わかる、それ悩むよね」等の共感を1文入れる

【避けること】
● 断定(「絶対」「必ず」「100%」)
● 個別商品名の推奨
● 他社批判
● 資料に無い内容の推測

【資料に無い質問への対応】
「その質問については社内資料に十分な情報がありません。今度先輩に確認してから、こちらのノウハウ集にも追記しますね」と返す。
```

### 4. 動作テスト (5分)

1. チャット欄に W3_テストデータ.xlsx のテスト質問1(初回訪問の切り出し方)を入力
2. NotebookLM が 資料を根拠にした回答を返すことを確認
3. 出典(どのページから)が明示されているか確認
4. トーンが 先輩っぽい・共感入り・セリフ例あり になっているか確認

---

## 若手への配布 (5分)

1. ノートブックを「共有」→ 「Google Workspace 内で共有」or 特定ユーザー招待
2. アクセス権: **閲覧者+チャット可** (編集不可、ソースは変更不可)
3. Slack / メールで URL を配布
4. 使い方の1枚メモを添付:
   - 「営業で悩んだ時、まず これに質問してみて」
   - 「答えられない質問は 先輩に聞いてね(で、後で追記します)」

## 更新運用

- **月1回、新しいノウハウを資料に追記** → NotebookLM がすぐ反映
- **月1回、若手の質問傾向をヒアリング** → よく聞かれる質問への回答を強化
- **年1回、ハンドブックの棚卸し**(古い情報の削除・修正)

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 回答が資料に無い情報を含む | カスタム指示に「資料にない内容は "分からない" と返す」を強調 |
| トーンが硬い | カスタム指示に「先輩っぽく」「共感を必ず入れる」を追記 |
| 出典が示されない | チャットで「ソースを明示してください」と追加依頼 |
| 若手が使ってくれない | 使い方1枚メモ+最初の1週間は横で見て使い方をレクチャー |
