# 営業ノウハウAI ボット構築ワーク(3ワーク構成)

## 全体像

トップ営業マンのノウハウを AI 化して、若手営業がいつでも質問できるボットを作る、3ワーク構成の教材です。
ライフプランAI ワーク(第17回)と同じ構成:「① 設計 → ② バイブコーディング → ③ デプロイとテスト」

**AIボットの完成イメージ**:
- 若手営業「初回訪問で緊張してます。話の切り出し方は?」
- AI(トップ営業マン)「わかる、それ悩むよね。まず5秒だけ相手を観察、目に留まった物から会話始めよう。トップ営業ならこう言う: "素敵な観葉植物ですね、育てるのお好きですか?"」

---

## ワーク構成

### ワーク① 設計書を作る(3時間)
- 演習1: 目的とゴール + ノウハウデータ設計
- 演習2: 質問カテゴリ + 作り方の選択(NotebookLM or GAS)+ トーン設計

### ワーク② バイブコーディング(3時間)
**W1 で選んだ作り方に応じて分岐**
- パターン A: **NotebookLM 版** — 資料アップ+Gem化(コード不要、超簡単)
- パターン B: **GAS 版** — ノウハウマスタ+Gemini API+サイドバー(履歴分析可)

### ワーク③ デプロイとテスト(3時間)
- 演習1: デプロイ(選んだ作り方別)+ 運用ルール
- 演習2: 10質問パターンで動作テスト+改善

## 「営業ノウハウAI」の中身

### ノウハウの構造(スプシ8列)

| 列 | 内容 | 例 |
|---|---|---|
| A: ID | NW-001 | NW-001 |
| B: カテゴリ | 8カテゴリのどれか | ① 初回訪問 |
| C: シチュエーション | どんな場面か | 初対面で緊張、話の切り出し方 |
| D: ノウハウ(コツ) | 具体的な考え方 | 5秒観察、目に留まった物から会話開始 |
| E: 決めゼリフ例 | 実際に使えるセリフ | 「素敵な観葉植物ですね、育てるのお好きですか?」 |
| F: 対象顧客タイプ | どんな相手向けか | 共通 |
| G: 出典 | 誰の経験か | 田中部長 |
| H: 有効/無効 | 現役かどうか | 有効 |

### 8カテゴリ

1. **① 初回訪問・初対面** — アプローチ、雰囲気作り
2. **② ヒアリング** — 本音を引き出す、聞くべき順番
3. **③ 提案・プレゼン** — 刺さる伝え方、数字の見せ方
4. **④ 反対処理** — 「今は考えたくない」等の切り返し
5. **⑤ クロージング** — 決断を促す言葉
6. **⑥ フォロー・アフター** — 契約後の関係維持、紹介依頼
7. **⑦ 顧客タイプ別** — 慎重派/経営者/シニア/若手夫婦 等への対応
8. **⑧ 失敗事例** — 過去の失敗から学ぶ教訓

### 顧客タイプ(8種)

慎重派 / 決断早 / 論理派 / 感情派 / 経営者 / シニア / 若手夫婦 / 主婦(主夫)

## 作り方の選び方(NotebookLM vs GAS)

| 観点 | NotebookLM 版 | GAS 版 |
|---|---|---|
| セットアップ | 15分 | 20〜30分 |
| 難易度 | ★☆☆ | ★★☆ |
| UI カスタマイズ | 不可 | 自由 |
| 質問履歴分析 | 手動 | 自動蓄積 |
| ノウハウ更新 | 資料差替 | スプシ追記 |
| 出典明示 | 自動(ページ番号) | 参照ID返す形 |
| 他ツール連携 | 難しい | 可能 |
| コスト | 無料 | Gemini API(無料枠内) |
| 向いている用途 | 素早く試したい / 資料が既にある | 継続運用 / 履歴分析 |

**判断のヒント**:
- **まず試したい / 使う人が少ない** → NotebookLM 版
- **社内で本格運用 / 育てていく** → GAS 版
- **迷ったら** まず NotebookLM 版で試して、需要が広がったら GAS 版に移行

## テスト質問 10パターン(W3で使用)

1. 初回訪問で緊張、話の切り出し方は?
2. ヒアリングで本音を引き出す最初の質問は?
3. 「今は考えたくない」の切り返しは?
4. 「他社と比較したい」の切り返しは?
5. 経営者への提案で気をつけることは?
6. シニア一人暮らしのお客様に安心してもらう話し方は?
7. 若手夫婦への学資保険提案の切り口は?
8. 契約意思確認のタイミングは?
9. 契約後の紹介依頼のタイミングと言い方は?
10. 提案書を出したが返事が来ない、フォローの言葉は?

各質問に「期待回答の骨子」がついているので、AI の実回答と比較して精度を測れます。

## 更新運用(継続改善)

- **週次(15分)**: 質問履歴を見返し "AI が答えられなかった質問" を発見
- **月次(30分)**: ベテランに "今月のノウハウ1件" を追加してもらう
- **年次(1時間)**: ノウハウ全件棚卸し、古い情報の無効化

継続的にノウハウを追加していくと、AI の回答範囲が広がり、"若手が1人で悩む時間" が減っていきます。

## 発展課題

1. **音声入力**: サイドバーに音声認識(Web Speech API)を追加
2. **LINE連携**: 若手が LINE で質問→AI が返信
3. **商談録音の自動ノウハウ抽出**: 文字起こし → AI がノウハウ候補提案
4. **満足度分析**: 質問履歴に "満足度" 列を追加、傾向分析
5. **多言語対応**: 英語圏の営業向けに英語で回答
