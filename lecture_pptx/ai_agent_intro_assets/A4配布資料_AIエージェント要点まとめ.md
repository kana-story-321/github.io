# AIエージェント 要点まとめ(持ち帰り用 A4 1枚)

## AIエージェント とは?

**「目標を伝えると、自分で複数のことを順にやってくれる AI」**

従来の生成AI(Gemini/ChatGPT)が「質問1つに答え1つ」だったのに対して、
AIエージェントは **目標 → 計画立て → ツール操作 → 結果判断 → 次の行動** を自動で繰り返す。

### 3つの特徴

1. **🎯 目標志向**: 手順の指示は不要、「〇〇作って」で自分で分解
2. **🛠 ツール活用**: ファイル操作・コマンド実行・Web検索・API を自ら使う
3. **🔁 自己修正**: エラーが出たら 自分で修正して再実行、上手くいくまで反復

---

## 従来AI と 決定的な違い

| 観点 | 従来の生成AI | AIエージェント |
|---|---|---|
| 動き方 | 1往復(質問→回答) | 数十ステップを自動連続 |
| ユーザー役割 | 毎ターン次を指示 | 目標伝達+承認、待つだけ |
| ツール | 生成のみ | 操作・実行まで自分で |
| 例 | 「メール文を書いて」→ 文が返る | 「今週の未返信30件返信して」→ 全部書いて 提案 |

---

## AIエージェント だからできること

1. **複雑なコード開発** — リポジトリ理解→修正→テスト→PR作成 まで一気通貫
2. **深いリサーチ** — 複数サイト横断→統合→レポート化
3. **繰り返し作業自動化** — 100件データ処理 / 100件PDF要約
4. **複数ツール連携** — スプシ→API→別スプシ の一連流れ

## 使い始めの 3ステップ

### Day 1: 選んで契約
Claude Pro or ChatGPT Plus を **月$20** で契約(毎月切替可)

### 1週間目: 簡単な作業を試す
- 「このスプシから〇〇集計して」
- 「このメール30件返信下書き作って」
- **"頼んで待つ" 感覚を体験** → 驚きと限界の両方が見える

### 1ヶ月目: 継続業務に組込み
週次レポート・コード開発など、定型業務を任せてみる → 元が取れれば継続

## 気をつけたい 3つのこと

⚠️ **コスト管理**: 従量課金の場合、放置で数万円/月。使用量アラート必須

⚠️ **セキュリティ**: ファイル操作・コマンド実行 が可能。顧客情報を含むデータは **情シスと事前調整**

⚠️ **監視が必要**: "自律的" = 予期せぬ行動もあり得る。初回は横で見る + 承認モード
