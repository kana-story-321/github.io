# 第11回 演習1 — FAQ チャットボット (GAS Web アプリ)

スライド「演習1 FAQ 設計 + Gemini で GAS Web アプリをバイブコーディング」の
デモ資材一式です。手を動かして「一次受け」を担うチャットボットを完成させます。

---

## 同梱ファイル

| ファイル | 内容 |
|---|---|
| `FAQ_チャットボット_デモデータ.xlsx` | 保険FAQ 10件のサンプルデータ (質問 / 回答 / カテゴリ) |

## セットアップ手順 (10分)

### 1. スプレッドシートを Google に取り込む

1. `FAQ_チャットボット_デモデータ.xlsx` を Google ドライブへアップロード
2. 右クリック →「アプリで開く」→「Google スプレッドシート」で開く
3. 自動で Google 形式に変換されます

### 2. GAS プロジェクトを作る

1. 上記スプレッドシートを開いた状態で「拡張機能」→「Apps Script」
2. 既存の `Code.gs` の中身をすべて削除して、同梱の `Code.gs` の内容を貼り付け
3. 左上の＋アイコン →「HTML」を選択 → ファイル名 `Index` で新規作成
4. `Index.html` の内容を貼り付けて保存

### 3. Gemini API キーを取得して登録

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを発行
2. Apps Script エディタ 左メニュー「⚙ プロジェクトの設定」
3. 「スクリプト プロパティ」→「プロパティを追加」

   | プロパティ | 値 |
   |---|---|
   | `GEMINI_API_KEY` | Google AI Studio で発行した API キー |

### 4. モデル検証 (推奨)

1. Apps Script エディタで関数 `verifyModel` を選び「実行」
2. 初回は権限承認 → 許可
3. ログに `✅ gemini-2.5-flash は利用可能` が出れば OK

### 5. ウェブアプリとしてデプロイ

1. 右上「デプロイ」→「新しいデプロイ」
2. 「歯車 (種類の選択)」→「ウェブアプリ」を選択
3. 設定:

   | 項目 | 値 |
   |---|---|
   | 説明 | 保険FAQ チャット (v1) |
   | 実行するユーザー | **自分** |
   | アクセスできるユーザー | **全員** |

4. 「デプロイ」→ 承認後、**ウェブアプリURL** をコピー

### 6. リッチメニューに配置

1. LINE Official Account Manager → リッチメニュー
2. ボタンの1つに「アクション: リンク」を選び、上でコピーした URL を貼り付ける
3. スマホでリッチメニューをタップ → チャット画面が開けば完成

## 動作確認

チャット画面で以下を試して、期待通り動くかチェック:

| 入力例 | 期待する動作 |
|---|---|
| `相談は無料ですか?` | FAQ回答 (料金) を丁寧に返す |
| `オンライン面談できますか?` | FAQ回答 (手続き) を返す |
| `私の契約の解約返戻金はいくら?` | **[HANDOFF]** で「担当者からご連絡します」 |
| `胸が痛いのですが病気ですか?` | **[HANDOFF]** (医療相談 → 対応外) |
| `頭が悪いの?` | **[HANDOFF]** (不適切話題 → 対応外) |

## 動作の内側

```
[ユーザー] → LINE リッチメニュー
    ↓ タップ(URL 起動)
[GAS Web アプリ URL] (LINE内ブラウザで開く)
    ↓ doGet: HTML返却
Index.html (チャット UI)
    ↓ fetch(?q=質問)
[GAS] doGet(e) → answerQuestion(q)
    ↓
FAQ シート → 知識として取得
    ↓
Gemini API に「システムプロンプト + FAQ知識 + 質問」を投げる
    ↓
{"text": "回答", "handoff": true/false} をパース
    ↓
UI に表示: 通常応答 / [担当者へ] タグ付き応答
```

## バイブコーディングで自分でゼロから作るときの Gemini プロンプト例

```
Google Apps Script で以下を作ってください。

【仕様】
- 現在開いているスプレッドシートの「FAQ」シート(列: 質問/回答/カテゴリ) を知識にする
- doGet で HTML チャット UI を返す (Index.html を include)
- doGet(?q=質問) で JSON 応答を返す: {"text": "...", "handoff": true/false}
- Gemini API (gemini-2.5-flash) を呼び、FAQ の内容を要約(200文字以内)で丁寧語返答
- FAQ に無い質問、契約個別内容、医療診断、不適切話題は [HANDOFF] で
  「担当者からご連絡します」と返す
- API キーはスクリプトプロパティ GEMINI_API_KEY

【HTML の見た目】
- 3軸トーン: 濃紺 #1F3A5F / ティール #0E7C86 / 山吹 #E8A33D
- LINE内ブラウザで開くのでモバイル前提、上部にヘッダー、下部に入力欄
- 「よくある質問」の候補ボタンを5個並べる
```

## 補足

- **モデル**: `gemini-2.5-flash` を採用 (2026年7月時点で GA・安定版・無料枠あり)
- **[HANDOFF] 判定**: Gemini の JSON 構造化出力 (responseSchema) で `handoff: true/false` を明示的に返させています。プロンプトへの「[HANDOFF]文字列付与」より安定します。
- **FAQ の更新**: スプレッドシートを直接編集するだけで反映。GAS の再デプロイは不要です。
- **本番運用**: FAQ が20件超になったら、Gemini の Gem (Knowledge) 機能への移行も検討してください。
