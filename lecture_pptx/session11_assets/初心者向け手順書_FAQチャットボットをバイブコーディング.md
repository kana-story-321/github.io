# 初心者向け手順書：FAQチャットボットをバイブコーディングで作る

**対象**：コードを書いたことがない方
**所要時間**：60〜90分
**最終ゴール**：LINE のリッチメニューから開ける「保険FAQ チャットボット」を自分で公開する

---

## 🗺 全体マップ（7ステップ）

| STEP | やること | 所要時間 |
|:---:|---|:---:|
| 0 | 準備（アカウント2つ + API キー） | 10分 |
| 1 | 🎨 FAQ を **設計** する（スプシで骨組み） | 15分 |
| 2 | 📊 FAQ を **スプレッドシート** に書く | 10分 |
| 3 | 🧙‍♂️ Gemini に GAS コードを **バイブコーディング依頼** | 15分 |
| 4 | 📦 GAS に貼って **デプロイ**（公開する） | 10分 |
| 5 | 🔗 リッチメニューに **URL を貼る** | 5分 |
| 6 | 🧪 **テスト**して改善する | 10〜15分 |

> 💡 **バイブコーディングとは**：コードを1文字も書かず、Gemini に「こういうの作って」と日本語でお願いして、返ってきたコードをコピペする作り方のこと。空気感（vibe）だけで作る、という意味。

## STEP 1 — 🎨 FAQ を「設計」する（15分）

**なぜやる？** 先にコードを書き始めると「何を答えさせるか」が決まっておらず、途中で止まります。まず **スプシで骨組み** を作るのが遠回りに見えて一番早いです。

### 1-1. 「今、お客様からよく聞かれる質問」を10個書き出す

思い出してみましょう。過去1年で3回以上聞かれた質問は、ほぼFAQ候補です。

**例（保険営業のよくある質問）**:

- 相談は無料ですか？
- どんな保険を扱っていますか？
- オンライン面談はできますか？
- 掛け捨てと積立の違いは？
- 持病があっても入れますか？
- 契約後の見直しはできますか？
- 解約したいときは？
- 資料請求はできますか？
- 保険料の相場は？
- 相談したら必ず契約しないといけない？

10個埋まらないときは、Gemini に頼みましょう👇

```text
私は保険営業のプランナーです。
初回相談前のお客様が LINE で聞いてきそうな質問を、
料金 / 手続き / 保険種類 / その他 の4カテゴリに分けて、
合計10個 挙げてください。
```

### 1-2. 各質問に「回答」を書く

このとき **答えられる質問／答えられない質問** を分けるのが超重要です。

| ✅ 答える | ❌ 答えない（担当者に繋ぐ） |
|---|---|
| 一般的な保険知識 | 個別契約の内容（「私の契約の解約返戻金は？」） |
| 相談方法・料金体系 | 医療診断（「胸が痛いのは病気？」） |
| 商品カテゴリの説明 | 複雑な税務・法律相談 |
| 事務所の場所・対応時間 | 特定商品の売り込み |

> 💡 **AI に答えさせない範囲を決める** のが FAQ設計の一番大事なポイント。ここを甘くすると事故ります。

### 1-3. カテゴリを付ける

各質問に **カテゴリ**（保険種類 / 手続き / 料金 / その他）を付けます。後で分析するときに役立ちます。

### ✅ 完了チェック

- [ ] 質問10個 が言語化できた
- [ ] それぞれに 200〜300文字 程度の回答を書いた
- [ ] カテゴリを付けた
- [ ] 「答えない範囲」を頭の中で決めた

## STEP 3 — 🧙‍♂️ Gemini にコードをバイブコーディング依頼（15分）

**ここが本番！** でも実は一番簡単。**依頼文をコピペするだけ**です。

### 3-1. Gemini を開く

[Gemini](https://gemini.google.com/) にログイン。

### 3-2. 依頼文（プロンプト）をそのまま貼る

以下を **そのままコピペ** して Gemini に送ります👇

```text
Google Apps Script (GAS) で、以下の仕様の「保険FAQチャットボット Web アプリ」を作ってください。

【スプレッドシート構成】
・シート名: 「FAQ」
・列: A=質問、B=回答、C=カテゴリ
・2行目以降にデータが入っている

【機能仕様】
1. doGet(e) で:
   - e.parameter.q があれば → JSON応答 {"text": "...", "handoff": true/false} を返す
   - なければ → Index.html のチャットUI を返す (HtmlService)
2. FAQ シートを読み込んで、Gemini API に「知識」として渡す
3. Gemini モデルは gemini-2.5-flash を使用
4. Gemini API キーはスクリプトプロパティ GEMINI_API_KEY から取得
5. システムプロンプト:
   「あなたは保険営業事務所の一次受け AI です。
    FAQ 知識にある内容は200文字以内で丁寧語で回答してください。
    FAQ にない質問、個別契約の内容、医療診断、不適切な話題には
    『担当者からご連絡します、少々お待ちください』と返し、
    handoff: true を設定してください。」
6. 応答は必ず {"text": "...", "handoff": true/false} の JSON 形式で

【HTMLの見た目】
・モバイル前提(LINE内ブラウザ想定)
・配色: 濃紺 #1F3A5F / ティール #0E7C86 / 山吹 #E8A33D
・上部にヘッダー「保険FAQ チャット」
・中央にメッセージ表示エリア(バブル形式)
・下部に入力欄+送信ボタン
・よくある質問の候補ボタンを 5個 上部に配置

必要に応じてコメントを付け、初心者でもわかる形で出力してください。
```

### 3-3. Gemini からの出力を確認

Gemini が **2つのファイル**（`Code.gs` と `Index.html`）を返してきます。

- コードブロック内の「コピー」アイコンで **それぞれコピー** します
- **まだ何もしません**。次のSTEPで貼ります

### つまずきポイント（よくある質問）

| Q | A |
|---|---|
| Gemini が短いコードしか返さない | 「もっと詳しく、Index.html も含めて完全なコードで」と追加依頼 |
| Gemini が API キーをコードに書いてしまう | 「API キーはスクリプトプロパティから取得するように修正して」と指示 |
| 変な英語で返ってくる | 「日本語のコメントで書き直して」と指示 |

### ✅ 完了チェック

- [ ] Gemini が `Code.gs` の内容を返してきた
- [ ] Gemini が `Index.html` の内容を返してきた
- [ ] 両方コピーできる状態にある

## STEP 4 — 📦 GAS に貼ってデプロイ（10分）

### 4-1. スプレッドシートから GAS エディタを開く

STEP 2 で作った スプレッドシートを開く → メニュー「拡張機能」→「**Apps Script**」

新しいタブで GAS エディタが開きます。

### 4-2. Code.gs を貼る

- 元々書いてある `function myFunction() {}` を **全部消す**
- Gemini がくれた `Code.gs` の内容を **まるごと貼り付け**
- Ctrl + S (Mac: Cmd+S) で **保存**

### 4-3. Index.html を新規追加

- 左の「ファイル」の隣の **＋アイコン** → 「HTML」を選択
- ファイル名を「**Index**」と入力（.html は自動で付きます）
- Gemini がくれた `Index.html` の内容を **全部貼り付け** → 保存

### 4-4. API キーをスクリプトプロパティに保存

1. 左メニュー「⚙ **プロジェクトの設定**」
2. 下の方の「**スクリプト プロパティ**」→「**プロパティを追加**」
3. 以下を入力:

    | プロパティ | 値 |
    |---|---|
    | `GEMINI_API_KEY` | STEP 0 でメモした AIzaSy... の文字列 |

4. 「**スクリプト プロパティを保存**」

### 4-5. モデルが使えるか確認（推奨）

1. コードエディタに戻る
2. 上部のプルダウンで **`verifyModel`** を選ぶ
3. 「▶実行」→ 初回は権限承認が出るので許可
4. 下部のログに **✅ gemini-2.5-flash は利用可能** と出れば OK

（`verifyModel` 関数がない場合は STEP 3 の依頼文に「モデル検証関数 verifyModel も追加して」と足して再生成）

### 4-6. Web アプリとしてデプロイ

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 左の歯車マークをクリック → 「**ウェブアプリ**」を選択
3. 設定:

    | 項目 | 値 |
    |---|---|
    | 説明 | 保険FAQ チャット v1 |
    | 実行するユーザー | **自分** |
    | アクセスできるユーザー | **全員** |

4. 「**デプロイ**」→ 権限を「許可」
5. 表示された **ウェブアプリ URL** を **必ずコピー**（メモ帳に一時保存）

> ⚠️ **URL は絶対にメモしてください**。次のSTEPで使います。閉じるとまた探すのが面倒。

### ✅ 完了チェック

- [ ] Code.gs と Index.html の 2つのファイルが GAS 内にある
- [ ] スクリプトプロパティに GEMINI_API_KEY が設定済み
- [ ] verifyModel で「利用可能」が出た
- [ ] ウェブアプリ URL をコピーした

| 症状 | 対処 |

| 返答が変 | FAQ の質問／回答を **より具体的に** 書き直して再度試す |

```text
     ↓
繰り返し
```

## 💡 バイブコーディングを続けるコツ

### 1. まず「作りたいもの」を日本語でスプシに書き出す

> 誰が / 何を入力すると / 何を返すのか

これが明確にならないと、AI にどう頼めばいいか分かりません。

### 2. AI には「初心者に説明する形」で頼む

> 「初心者にも分かるようにコメントを付けて」
> 「エラーが出たときの対処もコメントで書いて」

こう頼むと、後で自分で読み返しやすくなります。

### 3. うまく動かなくても諦めない

**エラーメッセージを全文コピー**して、Gemini に:

```text
以下のエラーが出ました。原因と修正方法を教えてください。
（エラーメッセージ全文を貼る）
```

すると 8割くらいは自己解決できます。

### 4. コードは「読める」で十分

**理解する必要はありません**。「なんとなくこの辺が何やってるかわかる」で OK。
プログラマーになるのが目的ではなく、**業務効率化のツールが作れる** のが目的です。

## 📚 用語辞典（この手順書に出てきた言葉）

| 用語 | やさしい説明 |
|---|---|
| **GAS**（Google Apps Script） | Google のサービス（スプシ・ドキュメント等）を自動化する、無料で使えるプログラミング機能 |
| **API キー** | 特定のサービス（Gemini など）を使うための「合鍵」。他人に見せてはいけない |
| **デプロイ** | 「公開する」の意味。作ったプログラムに URL が付き、誰でも(または指定した人が)使えるようになる |
| **ウェブアプリ** | ブラウザで開ける、URL を持ったプログラム。今回作るチャットボットはこれ |
| **doGet** | ウェブアプリの「玄関」の関数。URL でアクセスされたときに呼ばれる |
| **スクリプトプロパティ** | パスワードや API キーなど、コードに直書きしたくない情報を安全に保管する場所 |
| **HANDOFF**（ハンドオフ） | AI が対応困難と判断して、人間の担当者に引き継ぐこと |
| **プロンプト** | AI への「指示文」。良いプロンプト = 良い出力 |
| **バイブコーディング** | コードを書かず、AI に日本語で頼んで作る作り方 |

## お困りごと

うまく動かないときは、以下の順で確認してください:

1. **STEP 4-4** のスクリプトプロパティ に `GEMINI_API_KEY` が入っているか？
2. **STEP 4-6** のデプロイ設定「アクセスできるユーザー = 全員」になっているか？
3. **STEP 5-3** のリッチメニュー URL が正しく貼られているか？
4. **STEP 4-5** の `verifyModel` で ✅ が出たか？

それでもダメなら、**エラーメッセージのスクショ**を持って講師に相談ください🙌
