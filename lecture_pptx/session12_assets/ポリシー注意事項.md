# ⚠️ ポリシー・法令・運用上の注意事項

**このデモを本番運用する前に必ず確認**してください。

---

## 🎯 このデモの前提

- **配信内容**: お金の一般的な知識・公的制度の紹介 (助成金/税金/株為替/豆知識)
- **情報源**: 公的機関のホワイトリスト内サイトのみ
- **配信方法**: 全員一律の broadcast (無料枠 月200通内)
- **既存 Lステップ連携**: 触らない・壊さない前提

---

## 🚨 絶対にやってはいけないこと

### ❌ 1. LINE Developers の Webhook 設定を変更する

**理由**: 既存の Lステップが Webhook を使ってお客様の LINE 操作を受信しています。
これを上書きすると、Lステップの **タグ自動付与・シナリオ分岐・回答フォーム受信** が全部止まります。

**対策**: Messaging API のチャネル管理画面で「Webhook 設定」タブは開かない。
万一開いてしまってもURLは絶対に変えない。

### ❌ 2. 個別助言・個別診断を配信する

**理由**: 保険業法・金融商品取引法・税理士法などが「業として行うには資格が必要」と定めています。

**避けるべき配信例**:
- 「◯◯保険はA社が最安です」(特定商品の推奨)
- 「あなたの年収なら◯◯保険がベストです」(個別推奨)
- 「◯◯円まで税控除できます」(個別税務判断)
- 「今買うべき銘柄は◯◯です」(個別投資助言)

**安全な配信例**:
- 「iDeCo の税制優遇の仕組み(一般解説)」+ 「詳細は金融庁のサイトで」
- 「ものづくり補助金の対象と手続きの流れ」+ 「詳細は中小企業庁で」
- 「実質実効為替レートとは何か」(用語解説) + 「詳細は日銀のサイトで」

### ❌ 3. 個人ブログ・アフィリエイトサイトを情報源にする

**理由**:
- 情報の正確性が担保されない
- 商品への誘導を含む可能性
- **AIが情報源URLとして拾うと、そのまま生徒/顧客のLINEに流れる**

**対策**: ホワイトリストを公的機関のみに限定し、AIのプロンプトで明示する。
`isDomainAllowed_` 関数でドメイン検証してから配信予約に登録する。

### ❌ 4. 出典URLを付けずに配信する

**理由**: 信頼性が損なわれる。「その情報どこから?」と聞かれて答えられない配信は事故のもと。

**対策**: 本文末に必ず「出典: https://...」を付ける。
`Code_LINE配信.gs` の `sendOne()` は自動で本文末に出典URLを付加。

### ❌ 5. 収集した情報をそのまま自動配信する (人の目を通さない)

**理由**: AIは "自信を持って間違える" (ハルシネーション)。
出典URLがホワイトリスト内でも、AIの要約が事実と違う可能性がある。

**対策**: 「配信予約」シートで **人が OK/NG 判定** してから配信。
`sendOne` は `OK` 判定済み行のみを対象とする。

## ⚠️ 注意点 (許容範囲だが管理が必要)

### 🟡 A. 無料枠 月200通の管理

- 個人向け無料プランは月200通まで
- 「友だち数 × 配信回数」で消費
- 例: 友だち20人 × 週1配信 = 月80通 (安全)
- 例: 友だち50人 × 週1配信 = 月200通 (ギリギリ、他システムと共有だと超過リスク)

**対策**: `Code_LINE配信.gs` の月間カウンター機能を必ず有効化。
`MONTHLY_LIMIT` を実際の上限 (200) に設定。

### 🟡 B. 既存のLステップ配信との重複

- 同じ友だちに Lステップ配信と GAS配信が同時に届くと "うざい" 印象に
- 配信時間帯を分ける (Lステップが平日夜なら GAS は朝) など運用ルールを決める

### 🟡 C. 個人情報の扱い

- LINE の友だちIDは個人情報
- スプシに保存する場合はスプシの共有権限に注意
- 今回のデモ (broadcast) では個別ID不要なので、この問題は発生しない

### 🟡 D. Gemini API の利用料

- 無料枠は 1分あたり10回、1日あたり1500回 (2026年現在の目安、変動あり)
- 月次で数千円までの従量課金プランに切り替え可能
- 収集GAS を1日4カテゴリ×1回 = 月120回程度なら無料枠内

## 🚨 生徒質問対応集

### Q. 「AIに任せて全自動で配信したい」

**A**: AI は "自信を持って間違える" のがまだ完全に解けていない問題です。
公的サイトの情報を要約する過程で、数字や制度名を微妙に変えることがあります。
また金融・税務は法令が絡み、間違いが顧客の不利益や炎上に直結します。
**自動化するのは "集める" と "送る" だけ、"判断" は人**、という設計が現時点のベストプラクティスです。

### Q. 「もっと詳しい投資アドバイスを配信できない?」

**A**: 一般情報 (制度の解説など) は問題ありませんが、
「◯◯銘柄が今買いです」など個別の投資判断は **金融商品取引法** に触れます。
「詳しくは金融庁のNISA解説を」など、公式サイトへの誘導で締めるのが安全です。

### Q. 「Lステップの API 連携で送りたい」

**A**: Lステップの API 連携機能は有料プラン限定です。
無料プランで実現するなら、今回のデモのように
**LINE Messaging API を Push (broadcast) 送信専用で使う** のが唯一の選択肢です。
ただし Webhook 設定は絶対に触らないこと。
