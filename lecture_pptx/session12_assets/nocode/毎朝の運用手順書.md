# 毎朝5〜10分でお客様に有益情報を届ける — ノーコード運用手順書

**対象**: GAS の設定は難しいけれど、公式LINE で有益情報を届けたい方
**所要時間**: 毎朝 5〜10 分
**使うもの**: Gemini（Web）＋ スプレッドシート ＋ 公式LINE 管理画面

---

## 🌅 全体像

```
┌──────────────────────────────────┐
│  Gem 1:「お金情報 収集くん」        │  ←──  あなたが「今日◯件」と依頼
│  → Googleを検索して情報をTSVで返す │
└──────────────┬──────────────────┘
               │ TSVをコピー
               ↓
┌──────────────────────────────────┐
│  スプシ「配信素材」シート           │  ←──  貼り付け → OK/NG判定
└──────────────┬──────────────────┘
               │ OK 1行をコピー
               ↓
┌──────────────────────────────────┐
│  Gem 2:「LINE配信文 変換くん」      │
│  → 300字の LINE 用配信文に変換     │
└──────────────┬──────────────────┘
               │ 本文をコピー
               ↓
┌──────────────────────────────────┐
│  公式LINE メッセージ配信画面        │  ←──  貼って送信
└──────────────────────────────────┘
```

---

## 🛠 初回準備（1回だけ、20分）

### 1. Gemini アカウント準備

[Gemini](https://gemini.google.com/) にログイン。無料プランで OK。

### 2. Gem 1 を作成: 「お金情報 収集くん」

1. Gemini 画面 左サイドバー「**Gem を作成**」
2. 名前: `お金情報 収集くん`
3. 説明: `毎朝、公的機関のお金情報を集めてスプシに貼れる形で返す`
4. **カスタム指示**: 同梱の `Gem1_情報収集_指示文.md` の内容をそのまま貼り付け
5. **知識**: 空でOK
6. **機能**: **Google 検索を ON にする** ⚠️ ここが重要
7. 「保存」

### 3. Gem 2 を作成: 「LINE配信文 変換くん」

1. もう一度「Gem を作成」
2. 名前: `LINE配信文 変換くん`
3. 説明: `スプシの1行を、LINE で読みやすい配信文に変換する`
4. **カスタム指示**: 同梱の `Gem2_配信文変換_指示文.md` の内容をそのまま貼り付け
5. Google 検索は OFF で構いません
6. 「保存」

### 4. スプシを Google に取り込む

1. `お金情報配信_ノーコード用.xlsx` を Google ドライブへアップロード
2. 右クリック →「Google スプレッドシートで開く」
3. **「配信素材」シート** を今後毎朝使います

### 5. 公式LINE の準備

- 既存の公式LINE の管理画面にログインできる状態にしておくだけ
- **Webhook 設定など難しい設定は一切触りません**
- 「メッセージ配信」タブから毎朝手動で送るだけです

以上で準備完了です。

## 🌅 毎朝の運用（5〜10分、1日1回）

### STEP 1（1分）: Gem 1 に依頼

Gemini を開き、`お金情報 収集くん` を選択。以下のように依頼:

**例1**: 今日の情報を1件だけ
```
今日は税金・節税で気になるニュースを1件教えて。
```

**例2**: バランスよく複数件
```
今日は4カテゴリを1件ずつ、合計4件で。
```

**例3**: 特定のテーマで
```
今日はNISAかiDeCoの豆知識を2件、初心者向けで。
```

→ Gem がGoogle検索してTSVコードブロックを返します。

### STEP 2（1分）: スプシに貼り付け

1. Gem の出力の **右上「コピー」アイコン** をクリック（コードブロックの中身がコピーされる）
2. スプシの「**配信素材**」シートを開く
3. **一番下の空行** の A 列をクリック
4. **Ctrl + Shift + V**（Windows）または **Cmd + Shift + V**（Mac）で **プレーンテキストとして貼り付け**

> 💡 **Ctrl+V ではなく Ctrl+Shift+V** を使う理由: 通常の貼り付けだと書式が壊れることがあります。プレーン貼り付けなら、タブ区切りが自動で列に分かれます。

### STEP 3（1〜2分）: OK/NG 判定

1. 貼り付けた各行を **1 秒読む**
2. 「これはお客様に送りたい」→ **F 列に `OK`**
3. 「これはピンとこない、古い、誤情報っぽい」→ **F 列に `NG`**（送らずスキップ）
4. 迷ったら NG でOK

**判定のコツ**:
- 出典URL が上のホワイトリスト内か（変な URL は NG）
- タイトルを読んで **自分がお客様なら読みたいか**
- 3 件中 1〜2 件が OK でも十分（無理に全部送らない）

### STEP 4（1分）: Gem 2 で配信文に変換

1. OK にした行の **タイトル/要約/出典URL/カテゴリ** をスプシから選択してコピー
2. Gemini で `LINE配信文 変換くん` を選択
3. 以下の形式で貼り付けて送信:

```
タイトル: iDeCo改正で節税枠拡大 💰
要約: 2024年12月からiDeCoの拠出限度額が引き上げられ...（略）
出典URL: https://www.fsa.go.jp/ordinary/annai.html
カテゴリ: 税金・節税
```

→ Gem がLINE配信用にリライトして、コードブロックで返します。

**カスタマイズ依頼のコツ**:
- 「もう少し柔らかく」→ 冒頭に共感が入る
- 「もっと短く」→ 200字程度に
- 「3パターン欲しい」→ 柔らかめ・標準・かっちりめの3種を返す

### STEP 5（2分）: LINE に配信

1. 変換された **本文をコピー**（コードブロックの中身）
2. 公式LINE Manager にログイン → 「**メッセージ配信**」
3. 新規メッセージ → **本文を貼り付け**
4. 送信対象「**全員**」→ 送信

### STEP 6（30秒、オプション）: 履歴を残す

スプシの **「配信履歴」シート** に、配信したものを1行追記しておくと後で見返せます。

## 📅 週次のふりかえり（5分、毎週1回）

毎週金曜など決まった日に:

1. 今週配信したものを「配信履歴」シートで見る
2. 反応が良かったもの / 反応が薄かったものを **人の感覚でメモ**
3. 来週の依頼のときの参考にする

> 💡 反応データ（既読数など）は公式LINE Manager の「分析」タブで確認できます。

## 🎓 このワークから学ぶこと（意味の理解）

このワークは **GAS を使わずに** 情報の自動収集と配信を実現します。
「毎日AIに手動で依頼するだけなのに、なぜ意味があるのか？」を理解してください。

| 学び | 内容 |
|---|---|
| **Gem = プロンプトの資産化** | 一度作った Gem は毎回同じ品質で応答してくれる。「良いプロンプト」を1回書いて何十回も再利用できる |
| **AI ＋ 人の分業** | AI が情報を集め、人が OK/NG を判断する。この分業が誤情報の事故を防ぐ最後の砦 |
| **Google 検索連携** | Gem に検索を許可すると、AI の"知ってるつもり"を減らせる。出典URLがつくので信頼性UP |
| **ノーコードの強み** | 環境構築の壁がないので、明日から誰でも始められる。GAS への昇格は"忙しくなったら"でOK |

---

## ⚠️ 絶対にやってはいけないこと

1. **個別助言をコピペで送らない**（税務・投資判断）
2. **出典URLを消して配信しない**（信頼性が担保できない）
3. **公式LINE の Webhook 設定は絶対に開かない・触らない**（Lステップ連携が壊れる）
4. **AI の出力をそのまま送らない**（必ず自分の目で読んでから）
5. **アフィリエイト・個人ブログを情報源に混ぜない**（Gemのホワイトリスト外の出典URLはNG）

---

## 🚑 うまくいかない時

| 症状 | 対処 |
|---|---|
| Gem 1 の出力が TSV じゃなくて普通の文章 | 「TSV形式のコードブロックで返して」と追加依頼、または Gem のカスタム指示を再確認 |
| 出典URLがホワイトリスト外 | 「もう一度、●●.go.jp のみを情報源で」と追加依頼 |
| スプシへの貼り付けで列が分かれない | Ctrl+Shift+V（プレーン貼り付け）を使う、または データ→テキストを列に分割 |
| Gem 2 の配信文が長すぎる | 「200字以内に短縮して」と追加依頼 |
| 送信ボタンが押せない | 公式LINE の無料枠（月200通）を超えていないか確認、超えていたら翌月まで待つ |
