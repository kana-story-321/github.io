# 基礎組向け — Gem で毎朝5分の "お金情報自動配信" ワーク

**GAS の設定が難しい人向けの完全ノーコード版**です。

Gemini の **Gem 機能**（カスタム AI アシスタント）を 2 つ作って、
毎朝の手動運用で「AI 収集 → 人が判定 → AI 変換 → 手動配信」を回します。

---

## 同梱ファイル

| ファイル | 用途 |
|---|---|
| `Gem1_情報収集_指示文.md` | Gem 1「お金情報 収集くん」に貼るカスタム指示（丸ごとコピペ） |
| `Gem2_配信文変換_指示文.md` | Gem 2「LINE配信文 変換くん」に貼るカスタム指示（丸ごとコピペ） |
| `お金情報配信_ノーコード用.xlsx` | 3シート構成 (使い方 / 配信素材 / 配信履歴) |
| `毎朝の運用手順書.md` | 毎朝5〜10分のルーチン手順 |
| `補足_Gem運用ワーク.pptx` | 授業投影用スライド (6枚) |
| `README.md` | この文書 |

---

## 何ができるようになる？

- **毎朝5〜10分** の手動作業で、公的機関のお金情報をお客様のLINEに届けられる
- GAS も API キーも設定不要、Gemini の Web 画面と スプシ と LINE 管理画面 だけ
- Gem に一度指示を書けば、**毎日同じ品質** で応答してもらえる
- 個別助言・アフィリエイトサイト混入・Webhook 誤設定 などの事故を、Gem 側で防ぐ設計

## セットアップ（初回のみ、20分）

### 1. Gem 1 を作る（10分）

1. [Gemini](https://gemini.google.com/) にログイン
2. 左サイドバー「**Gem を作成**」
3. 名前: `お金情報 収集くん`
4. **カスタム指示**: `Gem1_情報収集_指示文.md` の中身を全部コピー → 貼り付け
5. **機能: Google検索を必ずON** ⚠️
6. 保存

### 2. Gem 2 を作る（5分）

1. もう一度「Gem を作成」
2. 名前: `LINE配信文 変換くん`
3. **カスタム指示**: `Gem2_配信文変換_指示文.md` の中身をコピー → 貼り付け
4. Google検索は OFF で OK（変換だけなので）
5. 保存

### 3. スプシを取り込む（3分）

1. `お金情報配信_ノーコード用.xlsx` を Google ドライブへアップ
2. 右クリック → 「Google スプレッドシートで開く」
3. 「使い方」「配信素材」「配信履歴」の 3 シートが入っていることを確認

### 4. 公式LINE

- 既存の公式LINE 管理画面にログインできる状態にしておくだけ
- ⚠️ **Webhook 設定は絶対に開かない・触らない**（Lステップが壊れます）
- 毎朝の「メッセージ配信」だけ使います

## 毎朝のルーチン（5〜10分）

詳細は `毎朝の運用手順書.md` に。全体像は:

```
① Gem 1 に依頼「今日◯件」          (1分)
② スプシに TSV を貼付               (1分)
③ 各行に OK / NG を判定             (1〜2分)
④ Gem 2 に OK 1行を貼付 → 配信文 (1分)
⑤ 公式LINE に貼って送信              (2分)
```

## トラブル対応

| 症状 | 対処 |
|---|---|
| Gem 1 の出力が TSV じゃない | 「TSV形式のコードブロックで返して」と追加依頼 |
| 出典URLがホワイトリスト外 | 「もう一度、●●.go.jp のみを情報源で」と追加依頼 |
| スプシ貼付で列が分かれない | Ctrl+Shift+V（プレーン貼付）を使う |
| Gem 2 の配信文が長すぎる | 「200字以内に短縮して」と追加依頼 |
| 送信できない | 無料枠 月200通 を確認、翌月まで待つ |

## 応用: 上級テクニック

慣れてきたらこんな依頼もできます:

- **バッチ変換**: Gem 2 に「以下の3行を配信文に変換して」と一度に複数渡す
- **キャラ設定**: Gem 2 に「もっと私の個性を出して、方言を少し混ぜて」と追加指示で自分らしさ
- **A/B テスト**: 同じネタで「柔らかめ」「かっちりめ」の2種を作って別の日に配信、反応比較
- **ジャンル配分**: Gem 1 に「今週は税金3・助成金3・株為替2・豆知識2の週間予定を」と週次計画も依頼可能
