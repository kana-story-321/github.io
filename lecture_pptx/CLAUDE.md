# lecture_pptx 開発メモ

## ワーク設計ルール(必ず守る)

### 紙のワークは作らない
- **一切の演習で "紙で設計" "紙で書き出す" "A4に整理" などの指示は禁止**
- 全ての設計・書き込み・記録は **Google スプレッドシート** or 既存のスプシテンプレ上で行う
- 「まず紙で骨組み」「手書きで整理」などの言い回しも使わない
- スプシに置くのが難しい図解のみ、スライド内で図解する

### 設計テンプレは "空欄フォーム" 方式
- 設計を求めるワークでは、以下の3種類のシートを用意して生徒の迷いをなくす:
  1. **テンプレ本体**(項目 / 考え方・判断基準(講師記入済) / あなたの答え(空欄) / 例)
  2. **記入例シート**(すべて埋まった完成見本、生徒はコピーせず参考にする)
  3. **相談ログ**(Gemini や講師と相談した内容と結論を残す)
- 「あなたの答え」列は薄いピンク背景 (#FCEEF0) で空欄を目立たせる

## パス / ツール

- xlsx 生成: Python + openpyxl、スクリプトは `/tmp/gen_s{回}_*.py`
- pptx 生成: Node + pptxgenjs、`node mk.js {回}` で `out/s{回}/` に出力
- 共通ライブラリ: `wlib.js`(baseSlide, exerciseSlide, coverSlide, summarySlide, COLOR, FONT)

## 出力 zip

- `/home/user/github.io/lecture_pptx_s{回}_all.zip` に演習pptx + 講師用pptx + デモ資材一式をまとめる
- 中身の階層は `第{回}回/ワーク01.pptx` `第{回}回/デモ資材/…` の形
