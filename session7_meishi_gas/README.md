# 第7回 演習：Drive 監視で名刺等シートを自動更新するGAS

第5回で作った顧客情報管理スプレッドシートの「名刺等」シートを自動化するワークです。
これまでは「Gemini チャットで名刺を整形 → スプレッドシートにコピペ」していた流れを、

> **指定したドライブフォルダに名刺画像やテキストファイルを置くだけで、自動的に「名刺等」シートに1行追加**

に変えます。同じお客様は重複登録されません。

---

## 同梱ファイル

| ファイル | 内容 |
|---|---|
| `顧客情報管理_デモ.xlsx` | デモ用スプレッドシート |
| `名刺等シート自動追加.gs` | 単体動作する GAS（Drive 監視＋Gemini API＋重複チェック付き） |
| `README.md` | このファイル |

---

## 動作の全体像

```
[ Drive フォルダ ]
   │  名刺画像 / メモ.txt / PDF
   ▼
[ 時間トリガー（5分ごと） ]
   │
   ▼
[ processDriveFolder() ]
   ├─ ファイル種別判定（画像/PDF はインライン、テキストは本文に埋め込み）
   ├─ Gemini API (gemini-3.5-flash) で項目を抽出
   ├─ 重複チェック（メール一致 / 電話一致 / 氏名一致＋連絡先空）
   ├─ 重複なし → 「名刺等」シートに 1 行追加
   └─ ファイルを「処理済み」サブフォルダへ移動（失敗時は「エラー」へ）
```

---

## モデル検証について

- 採用モデル：**`gemini-3.5-flash`**（2026年6月時点で GA・安定版／1M トークンコンテキスト／画像・PDF 対応）
- コード内に `verifyModel()` 関数を入れています
- メニュー「名刺取り込み」→「**利用可能なモデルを確認**」を実行すると、自分の API キーで実際にモデル一覧を取得して、設定モデルが使えるか検証できます

---

## セットアップ手順

### 1. スプレッドシートを開く

1. `顧客情報管理_デモ.xlsx` を Google ドライブにアップロード
2. 右クリック →「アプリで開く」→「Google スプレッドシート」で開く

### 2. 監視用ドライブフォルダを準備

すでに [指定フォルダ](https://drive.google.com/drive/folders/1tS5v5PYLRSrO7Uq4q8miLldpmLqYCFKz?usp=sharing) があれば、その ID（`1tS5v5PYLRSrO7Uq4q8miLldpmLqYCFKz`）をそのまま使えます。

別フォルダにしたい場合は、自分のドライブで新規フォルダを作って、URL の `folders/` の後ろの ID をコピーしておきます。

### 3. Gemini API キーの取得

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを発行
2. キーをコピー

### 4. GAS 貼り付け + スクリプトプロパティ設定

1. スプレッドシートで「拡張機能」→「Apps Script」
2. 既存コードを削除し、`名刺等シート自動追加.gs` の中身を貼り付けて保存
3. 左メニュー「⚙ プロジェクトの設定」→「スクリプト プロパティ」→「プロパティを追加」
4. 以下を追加:

   | プロパティ | 値 |
   |---|---|
   | `GEMINI_API_KEY` | Google AI Studio で発行した API キー |
   | `DRIVE_FOLDER_ID` | 監視するフォルダの ID（既定フォルダを使うなら省略可） |

### 5. 動作確認＋トリガー設定

1. スプレッドシートに戻ってリロード（F5）
2. メニュー「名刺取り込み」→「**利用可能なモデルを確認**」をクリック
   - 初回は権限承認のダイアログ → 許可
   - 「✅ 設定モデル「gemini-3.5-flash」は利用可能です。」と表示されればOK
3. ドライブの監視フォルダに名刺画像 or `.txt` ファイルを 1〜2 個入れる
4. メニュー「名刺取り込み」→「**今すぐドライブを確認**」をクリック
5. 結果がアラートで表示され、「名刺等」シートに新しい行が追加される
6. メニュー「名刺取り込み」→「**自動実行トリガーを設定（5分ごと）**」をクリック
   → 以後、ファイルを置けば 5 分以内に自動で取り込まれます

## 重複チェックの仕様

以下のいずれかに当てはまった場合は「重複」と判定して登録をスキップします。

| 判定 | 条件 |
|---|---|
| ① メール一致 | 既存行のメールアドレスと完全一致（小文字化・前後空白除去） |
| ② 電話一致 | 数字部分のみで完全一致（ハイフン・空白は無視） |
| ③ 氏名一致 | 氏名が一致 **かつ** メール・電話が両方とも「記載なし」 |

- 同一バッチ内（一度の実行で複数ファイル処理時）も、追加した行をインデックスに即時反映するため重複しません
- 「記載なし」「不明」は重複判定の対象外として扱います

---

## 対応ファイル形式

| 種別 | MIME | 処理方法 |
|---|---|---|
| 画像 | `image/jpeg`, `image/png`, `image/heic` など | Gemini に画像として送信 |
| PDF | `application/pdf` | Gemini に PDF として送信 |
| テキスト | `text/plain`, `text/csv` | 本文を読み取ってプロンプトに埋め込み |
| その他（Google ドキュメント等） | — | スキップ |

---

## 注意点

- **Google Apps Script には「ファイル追加イベント」のトリガーは存在しません。** 5 分ごとの時間トリガーで監視フォルダをポーリングするのが標準的なやり方です。
- 監視フォルダ内に既に多数のファイルがある状態でトリガーを開始すると、それらすべてが処理されます。最初は空のフォルダから始めるか、テストしたいファイルだけ残してください。
- 1 回の実行で大量のファイルを処理すると Gemini API のレート制限・Apps Script の 6 分実行制限にかかる可能性があります。
- ファイルは処理後に **同じドライブフォルダ内の `処理済み` サブフォルダ** に自動移動します。エラー時は `エラー` サブフォルダへ移動します。

## バイブコーディングで自分で作るときの Gemini への依頼例

```
Google Apps Script で、以下の機能を作ってください。

【目的】
指定した Google Drive フォルダに名刺画像・テキストファイル・PDF が
追加されたら、Gemini API で内容を抽出してスプレッドシートに自動追加する。

【シート構成】
- 「名刺等」シート：11列の顧客情報
  （タイムスタンプ／氏名／メール／電話（ハイフンなし）／年代／
   家族構成／お困りごと種類／お困りごと詳細／連絡希望[平日]／
   連絡希望[週末]／特記事項）

【動作】
1. 時間トリガーで 5 分ごとに指定ドライブフォルダを確認
2. 新しいファイルがあれば Gemini API (gemini-3.5-flash) で項目を抽出
3. 「名刺等」シートの一番下に1行追加（重複は登録しない）
4. 処理済みファイルは「処理済み」サブフォルダに移動
5. エラーは「エラー」サブフォルダに移動

【セキュリティ・設定】
- Gemini API キーはスクリプトプロパティ GEMINI_API_KEY
- 監視フォルダ ID はスクリプトプロパティ DRIVE_FOLDER_ID

【重複チェック】
- メール完全一致 / 電話完全一致 / 氏名一致＋連絡先空 のいずれかで重複扱い

【検証機能】
- メニューに「利用可能なモデルを確認」を追加し、Gemini API の models エンドポイントから
  generateContent が使えるモデル一覧を取得して、設定モデルが含まれているか確認できるようにする

ファイル種別：画像と PDF は inline_data でバイナリ送信、テキストは本文に埋め込む。
記載がない項目は "記載なし" として補完してください。
```

## トラブルシューティング

| 症状 | 確認ポイント |
|---|---|
| メニューが表示されない | スプレッドシートをリロード（F5）。スクリプトが保存されているか確認 |
| 「GEMINI_API_KEY を設定して」と出る | プロジェクト設定 → スクリプトプロパティを確認 |
| ❌ モデルが利用できません | API キーの権限／無料枠／モデル名のスペル確認 |
| トリガーが動かない | 「トリガー」画面（時計アイコン）で `processDriveFolder` が登録されているか／実行履歴のエラー確認 |
| 「シートが見つかりません」 | 「名刺等」シートの名前を変えていないか確認 |
| 重複なのに追加された | メール/電話の表記揺れ（全角・空白）を確認。プロンプトの「ハイフンなしの数字のみ」が効いているか |
