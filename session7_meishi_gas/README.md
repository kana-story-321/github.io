# 第7回 演習：名刺等シートに自動で1行追加するGAS

第5回で作った顧客情報管理スプレッドシートの「名刺等」シートを自動化するワークです。
これまで手作業で「Gemini チャットで名刺を整形 → スプレッドシートにコピペ」していた流れを、
**入力シートにテキストを貼り付け → ボタン1つで「名刺等」に追加** に変えます。

---

## 同梱ファイル

| ファイル | 内容 |
|---|---|
| `顧客情報管理_デモ.xlsx` | 既存のスプレッドシートに「入力」シートを追加したもの |
| `名刺等シート自動追加.gs` | 単体動作する GAS（Gemini API 呼び出し付き） |
| `README.md` | このファイル |

---

## モデル検証について

GAS 内で使う Gemini モデルは **`gemini-3.5-flash`**（2026年6月時点で GA・安定版／1M トークンコンテキスト）です。

- 利用可能であることを 2026/06 時点のドキュメントで確認済み
- コード内に `verifyModel()` 関数を入れています
- メニュー「名刺取り込み」→「**利用可能なモデルを確認**」を実行すると、自分の API キーで実際にモデル一覧を取得して、設定モデルが使えるか検証します

---

## セットアップ手順

### 1. スプレッドシートを開く

1. `顧客情報管理_デモ.xlsx` を Google ドライブにアップロード
2. 右クリック →「アプリで開く」→「Google スプレッドシート」で開く

### 2. Gemini API キーを取得

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセス
2. 「Create API key」で API キーを発行
3. キーをコピー

### 3. GAS の貼り付け＋ API キーの設定

1. スプレッドシートで「拡張機能」→「Apps Script」
2. 既存のコードをすべて削除し、`名刺等シート自動追加.gs` の中身を貼り付けて保存
3. 左メニュー「⚙ プロジェクトの設定」を開く
4. 「スクリプト プロパティ」セクションの「スクリプト プロパティを追加」をクリック
5. 以下を追加:
   - プロパティ: `GEMINI_API_KEY`
   - 値: 先ほどコピーした API キー
6. 「スクリプト プロパティを保存」

### 4. 動作確認

1. スプレッドシートに戻ってリロード（F5）
2. メニュー「名刺取り込み」→「**利用可能なモデルを確認**」をクリック
3. 「✅ 設定モデル「gemini-3.5-flash」は利用可能です。」と表示されればOK
4. 「入力」シートの A2 に名刺テキストを貼り付ける
5. メニュー「名刺取り込み」→「テキストから1行追加」
6. 初回は権限承認のダイアログが出るので許可
7. 「名刺等」シートの最下行に新しい行が追加される

## バイブコーディングで自分で作るときの Gemini への依頼例

このコードを Gemini にゼロから作ってもらうときの依頼テンプレ：

```
Google Apps Script で、Google スプレッドシートに以下の機能を追加してください。

【シート構成】
- 「入力」シート：A2 セルに名刺やメモのテキストを貼り付ける
- 「名刺等」シート：11列の顧客情報（氏名／メール／電話／年代／家族構成／お困りごと種類／お困りごと詳細／連絡希望[平日]／連絡希望[週末]／特記事項 など）

【動作】
1. メニュー「名刺取り込み」→「テキストから1行追加」をクリック
2. 「入力」シートのA2のテキストを Gemini API（gemini-3.5-flash）に送って、
   上記11列に対応する項目を JSON 形式で抽出
3. 抽出結果を「名刺等」シートの一番下に1行として追加
4. A2 をクリア

【セキュリティ】
- Gemini API キーはスクリプトプロパティ「GEMINI_API_KEY」から取得

【検証機能】
- メニューに「利用可能なモデルを確認」を追加し、Gemini の models エンドポイントから
  使えるモデル一覧を取得して、設定モデル(gemini-3.5-flash)が含まれているか確認できるようにする

記載がない項目は "記載なし" として補完してください。
```

## 補足

- 画像（名刺の写真）入力にも対応させたい場合は、`callGemini_` の `parts` に inline_data でBase64画像を渡せばOK
- 抽出精度を上げたい場合は、温度（`temperature`）を 0 に近づけたり、Few-shot 例をプロンプトに足してください
