# 第7回 演習1 — 商談ログから顧客情報を別シートに転記する

## 同梱ファイル

| ファイル名 | 内容 |
|---|---|
| `商談ログ_デモデータ.xlsx` | デモ用のスプレッドシート（「商談ログ」12件＋空の「顧客マスター」） |
| `商談ログから顧客マスターへ転記.gs` | Google Apps Script のコード（完全版／単体動作） |

---

## セットアップ手順

### 1. スプレッドシートの準備

1. `商談ログ_デモデータ.xlsx` を Google ドライブにアップロード
2. 右クリック →「アプリで開く」→「Google スプレッドシート」で開く
3. 自動で Google スプレッドシート形式に変換される

### 2. GAS コードの貼り付け

1. 開いたスプレッドシートで「拡張機能」→「Apps Script」を選択
2. 既存の `Code.gs` のコードをすべて削除
3. `商談ログから顧客マスターへ転記.gs` の中身をコピーして貼り付け
4. 保存（Ctrl + S）

### 3. 動作確認

1. スプレッドシートに戻ってリロード（F5）
2. 上部メニューに「顧客管理」が追加されている
3. 「顧客管理」→「顧客マスターを更新」をクリック
4. 初回は権限承認のダイアログが出るので許可
5. 顧客マスターシートに6社（田中商事／鈴木製作所／佐藤工業／高橋食品／渡辺商店）が
   入り、最終商談日が反映される

### 4. テストパターン

商談ログに新しい行を追加して再実行：

| パターン | 期待する動作 |
|---|---|
| 既存のお客様で新しい日付の行を追加 | 顧客マスターの「最終商談日」が更新 |
| 新規のお客様の行を追加 | 顧客マスターに新しい行が追加 |
| 既存のお客様で古い日付の行を追加 | 顧客マスターは変化なし（最新日付は維持） |

---

## バイブコーディングで作りたいときの Gemini への依頼例

```
Google Apps Script で、Google スプレッドシートの
「商談ログ」シート（列：日付／お客様名／商談内容／担当者／商談時間）から、
「顧客マスター」シート（列：お客様名／最終商談日／備考）へ
自動転記するコードを書いてください。

条件：
- 同じお客様は2行作らず、最終商談日を最新の日付に更新する
- 新規のお客様は新しい行として追加する
- お客様名は商談ログのままを使う
- スプレッドシートを開いたら「顧客管理」メニューが出て、
  そこから手動で実行できる
```
