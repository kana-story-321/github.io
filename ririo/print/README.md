## 商品別QR（?p=id）について

- 商品別QRから開くと、その商品のキャラが必ず出ます（その日まだクッキーを割っていない場合。1日1枚なので、割ったあとはその日の結果が表示されます）。
- アンケートの「今日食べたのはどれ？」で、その商品が最初から選ばれた状態になります。季節外の商品でも選択肢に出ます。

## 印刷のコツ

- 拡大・縮小せず **100%（実際のサイズ）** で印刷してください（「用紙に合わせる」はオフ）。
- 光沢紙は照明が反射して読み取りにくくなるので、**マット紙**がおすすめです。
- シールは点線に沿ってカットしてください（丸シール用の台紙に貼る場合は、色の外枠に合わせて切ります）。
- 印刷したら、いちど自分のスマホで読み取れるか確認してください。
