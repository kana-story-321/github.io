# ホームページ（Lovable）に「お客様の声」を出す

おみくじクッキーのページで「ホームページに掲載OK」のまま送られた口コミのうち、
承認ページ（https://gbp.ai-mottainai.jp/ririo/admin.html）で「掲載する」を押したものが、ホームページに表示されます。

## Lovable に貼る指示文

下の枠の中をそのまま Lovable のチャットに貼ってください。

```
トップページの適切な位置（お店の紹介の後あたり）に「お客様の声」セクションを追加してください。

データは次のURLから、ページを開いたときに fetch で取得します（ログイン不要・CORS許可済み）。
GET https://gbp-api.ai-mottainai.jp/reviews?limit=12

返ってくるJSONの形：
{
  "reviews": [
    {
      "id": "0672e897-c64",
      "date": "2026年10月",
      "product": "栗のモンブラン",
      "text": "モンブランは栗の味が濃くて、甘さ控えめでした。…",
      "photos": ["https://gbp-api.ai-mottainai.jp/reviews/photo/0672e897-c64/0"]
    }
  ]
}

表示のしかた：
- 見出しは「お客様の声」、小さく「ご来店いただいたお客様からいただいた感想です」
- 口コミ1件を1枚のカードにして、スマホでは1列、PCでは2〜3列で並べる
- カードには、写真（あれば1枚目を上に。タップで残りも見られると嬉しい）、本文、下に小さく「商品名・年月」
- 本文が長いときは4行で切って「続きを読む」で開く
- 最初は6件表示し、「もっと見る」で残りを表示
- 0件のとき、または読み込みに失敗したときは、セクションごと表示しない
- 本文は文字列としてそのまま表示する（HTMLとして解釈しない）
- サイト全体の色・フォントに合わせて、やさしい雰囲気で
- 最後に「Googleマップの口コミも見る」リンク（https://www.google.com/maps/search/?api=1&query=Sweet+Season+ririo）を置く
```

## 動きの確認

- ブラウザで https://gbp-api.ai-mottainai.jp/reviews を開くと、今掲載中の口コミがJSONで見られます。
- まだ1件も承認していないときは `{"reviews":[]}` です（ホームページにはセクションが出ません）。
