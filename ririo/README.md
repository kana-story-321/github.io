# Sweet Season ririo ｜ おみくじクッキー × 口コミ

公開URL: https://gbp.ai-mottainai.jp/ririo/

QRコードを読む → クッキーを割って占い → 答え合わせの質問が伸びていく → 口コミ文章が育つ → コピーしてGoogleマップへ、という流れのスマホ向けページです。

## ファイル

| ファイル | 役割 |
|---|---|
| `config.js` | **お店ごとに書き換える場所。** 店名、Googleの口コミURL、商品＝キャラ、占い文、選択肢 |
| `index.html` / `style.css` / `app.js` | ページ本体 |

## 使い方

1. `config.js` の `shopName` と `gbpReviewUrl` を設定します。`gbpReviewUrl` は、Googleビジネスプロフィールの「クチコミを依頼」で表示されるURLです。
2. 商品・キャラ・占い文を、お店の実際の商品に置き換えます。
3. 箱のシールごとにQRコードを分けたい場合は、URLの最後に `?p=商品ID` を付けます（例: `https://gbp.ai-mottainai.jp/ririo/?p=pudding`）。そのキャラが出て、最初の質問ではその商品が選ばれた状態になります。
4. 動作確認で「今日のクッキー」をやり直したいときは、`?reset` を付けて開きます。

## キャラの受け取りと進化

- QRを読んでクッキーを割ると、その日の運勢とキャラが出ます（1日1回）。この時点では、キャラはまだ図鑑に入りません。
- 答え合わせ（お店へのアンケート）を最後まで答えると、完成画面にキャラが「受け取り待ち」のシルエットで表示されます。
- 「コピーして Google マップを開く」と「Googleには書かずに進む」の**どちらを押しても**、同じように受け取れます（1日1回まで）。Googleマップを開いた場合は、ページに戻ってきたときに受け取りの演出が出ます。口コミの投稿を受け取りの条件にはしていません（Googleの規約・ステマ規制への対応）。
- 定番キャラは3段階の「いきもの」です（`evolve.js`）。最初に受け取った定番キャラが「相棒」になり、受け取るたびになかよし度が1たまります。3回で生まれ、7回で進化します。
- クッキーを割ったとき、5%の確率で進化しきった姿がいきなり出ます（`RARE_EVOLVED_RATE`）。
- 図鑑は定番キャラを段階ごとに3マスずつ表示します。記録はそのスマホのブラウザに保存されます。日付を変えて確認する例: `?date=2026-11-01`

## キャラの画像

- `img/chara/{商品ID}-{段階}.webp` が表示に使う画像です（Canva の画像生成AIで清書し、背景を透明にしたもの）。季節限定キャラは段階1だけです。
- 画像が読めないときは、`evolve.js` / `chara.js` の手描きSVGで表示します。

## 買ったお菓子の写真

- 答え合わせの最後のほうに「買ったお菓子の写真はありますか？」があり、3枚まで載せられます（任意）。写真はスマホの中で縮小してから使います。
- 完成画面に写真を表示し、「Googleマップで『写真を追加』からこの写真を選ぶ」と案内します（Googleへの添付は、お客さん自身の操作です）。
- `feedbackEndpoint` を設定していれば、写真もお店に届きます。下のApps Scriptの例では、Googleドライブに保存します。

## 待ち受け画像

- 占いの結果画面の「📱 待ち受け画像をもらう」から、スマホの縦長サイズ（1170×2532）のキャラ画像を保存できます。対応しているスマホでは共有メニューが開くので、「画像を保存」を選びます。
- 図鑑で集めたキャラをタップすると、そのキャラの待ち受け画像をもう一度もらえます。
- 上部（時計の位置）と下部（ボタンの位置）は空けて、キャラ・運勢・店名を中央にまとめています。季節限定キャラは季節の色、SR・SSR は光る背景になります。

## 季節限定キャラ

- `config.js` の商品に `seasons: ["halloween"]` のように書くと、その季節のあいだだけ登場します。季節の期間は `seasons` で設定します。
- 季節中は、季節限定キャラが出やすくなります（`seasonalBoost`）。また、「今日食べたのは？」の選択肢で季節ものが先頭に並びます。
- ハロウィンはクッキーがジャック・オ・ランタンの顔に、クリスマスは雪の飾りになり、ページの色も変わります。
- 図鑑は「定番」と「季節限定」に分かれて表示されます。季節外のキャラには「〇〇限定」、季節中のキャラには「出現中！」と表示されます。
- 日付を指定して見た目を確認できます。例: `?date=2026-12-10&reset`

## AIで深掘りする（任意）

`config.js` の `aiEndpoint` に、リポジトリ直下の `worker/` を公開したURLを設定します。空のままなら、AIを使わずにあらかじめ用意した質問と文章の組み立てで動きます。手順はリポジトリ直下の README を見てください。

## アンケート結果を受け取る（任意）

`feedbackEndpoint` に Google Apps Script のウェブアプリURLを設定すると、回答（お店へのリクエストを含む）が送られます。スプレッドシートに貼るスクリプトの例は次のとおりです。

```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  // 写真（最大3枚）はGoogleドライブの「口コミ写真」フォルダに保存して、リンクを表に残す
  const folders = DriveApp.getFoldersByName("口コミ写真");
  const folder = folders.hasNext() ? folders.next() : DriveApp.createFolder("口コミ写真");
  const links = (d.photos || []).map((src, i) => {
    const blob = Utilities.newBlob(Utilities.base64Decode(src.split(",")[1]), "image/jpeg", `${d.at}-${i + 1}.jpg`);
    return folder.createFile(blob).getUrl();
  });
  SpreadsheetApp.getActiveSheet().appendRow([
    d.at, d.fortune.productId,
    d.answers.map(a => a.question + "：" + JSON.stringify(a.answer)).join("\n"),
    d.review, links.join("\n"),
  ]);
  return ContentService.createTextOutput("ok");
}
```

## 規約まわりで守っていること

- 特典（くわしい運勢・キャラの受け取り）は、お店へのアンケートに対するお礼で、**Googleへの投稿を条件にしていません**。投稿する・しないのどちらのボタンからでも同じように受け取れます。
- 評価に関係なく、全員に同じGoogle投稿ボタンを表示しています（レビューゲーティングをしない）。
- 文章はお客さん本人が編集してから投稿する前提で、「自分の言葉を足してね」と案内しています。
- お店へのリクエストは口コミの文章には入れず、お店だけに届けます。
