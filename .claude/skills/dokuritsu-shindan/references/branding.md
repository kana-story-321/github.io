# 方向性とブランディング

ブランディングは見た目（ロゴや色）の話ではなく、**「誰に、何者として覚えてもらうか」を決めること**。診断で見直した方向性を、言葉と発信に落とし込む。

## 1. 強みの棚卸し

次の4つを書き出してもらう（聞き取りの内容から先に下書きを作り、確認してもらうと早い）。

| 項目 | 例 |
|---|---|
| **経験** | 10年間、病院の事務と採用を担当 |
| **得意なこと** | 人の話を整理して文章にする、表計算での仕組み化 |
| **好きなこと・続けられること** | 小さな組織の人と一緒に仕事をする |
| **やりたくないこと** | 大企業の長い会議、休日の対応、安売り |

強みは単体ではなく**掛け合わせ**で見る。「Web制作ができる人」は多いが、「医療業界の採用を知っているWeb制作者」は少ない。掛け合わせが珍しいほど、比べられにくく、価格で選ばれにくい。

## 2. 誰に向けるか

- 一番価値を出せて、一番困っていて、**自分がその人たちの言葉や事情を知っている**集団を選ぶ。
- 最初は狭すぎるくらいでよい。狭く始めて評判を作り、隣の集団に広げる。
- 自分がもともと属している業界・地域・コミュニティから選ぶと、最初の顧客が見つけやすい。

## 3. ポジショニングの一文

形：「**[誰]** のための **[何]**。**[競合・代わりの手段]** と違って **[違い]**。」

- 声に出して10秒で言える長さにする。
- 「誰」は具体的に（×中小企業 → ○社員10人以下のクリニック）。
- 「違い」は相手にとっての利益で書く（×丁寧な対応 → ○院長が採用に使う時間を月10時間減らす）。

真似されにくい理由を3〜4点添える：経歴の掛け合わせ、業界の知識、人脈・紹介元、蓄積していく事例・実績。

## 4. 肩書きとプロフィール

**肩書き**を3案出す。
- 何をする人か、すぐ分かること（造語だけの肩書きは避ける）
- 例：「クリニック専門の採用Web制作」「医療採用の仕組みづくり担当」

**プロフィール文**を2つの長さで作る。
- **100字版**（SNSの自己紹介用）：誰の・何を・どう良くするか＋一番の実績
- **300字版**（ホームページ・提案書用）：上の内容＋経歴の掛け合わせ＋なぜこの仕事をするか＋依頼の方法

## 5. 発信の方針

発信は「宣伝」ではなく「信頼を貯めること」。最初の顧客は紹介や直接の提案で取り、発信は中長期の集客として育てる。

- **場所を1〜2つに絞る**（顧客がいる場所を選ぶ。例：企業相手なら note・LinkedIn・メールマガジン、地域の店相手なら Instagram・Googleビジネスプロフィール）
- **自分のリストを持つ**：SNSは借りている場所。メールやLINE公式アカウントなど、直接連絡できる手段に顧客を集める。
- **3段階の発信テーマ**を各3案出す：
  1. **教える**：仕事で学んだことを惜しまず出す（例：採用ページでよくある失敗5つ）
  2. **刺激を与える**：自分の挑戦、失敗、変化を正直に見せる（例：独立1か月目の数字）
  3. **楽しませる**：業界のあるあるなど、思わず共有したくなるもの
- **続けられる頻度**を決める（例：週1回の記事、月1回のお便り）。頻度より継続を優先する。

## 6. 避けるべき見せ方

- 何でもできる人として見せる（「Web・動画・SNS・コンサル、何でも対応」）→ 誰にも刺さらない
- 安さを売りにする → 安い顧客が集まり、価格を上げられなくなる
- 実績がないのに大きく見せる → 信用を失う。小さな実績を正直に積み上げるほうが強い
- 流行りの言葉だけの肩書き → 何をする人か伝わらない
- 診断で見直した方向性と違うことを発信する → ブランドが薄まる
