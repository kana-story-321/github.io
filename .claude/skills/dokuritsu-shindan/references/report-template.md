# レポートの構成

フル診断・プランのレビューで書く Markdown レポートの構成。各章は中身を省略せず、特に「4. 指摘」「7. お金の計算」「8. 撤退基準と最初の一歩」は削らない。字数を合わせるための書き直しはしない。
